Hz，收尾 147 Hz 短闷响，总长 0.62 s）；全部落在小喇叭放得出的频段，`e2e_av.js` 新增三条护栏（必须有 square、最低音 ≥100 Hz、主音 ≥200 Hz）。**v24 起学生有自己的主页**（T-014 第 2 加了两个手写题型**（T-018）：**汉字听写**（听一个词，在田字格里默写，两字词就给两格；写完点「写好了」→ 格子底下浮出浅绿的正确字 → 自己/老师对一下，「写对了」或「没写好，重写」，重写不判死、一题最多记 1 次错）与**描红汉字**（格子底下一个浅灰楷体字，照着描，描完直接过）。离线单文件没有手写识别，所以这两个题型不假装自动判分；**描红记的是「辅助完成」（hinted），不记独立答对**，否则描两遍就进「已掌握」，档案会骗老师。**v26 修「拼词语」的两个毛病**（T-019）：① 一屏字块里任意两字都能被孩子拿去拼，「一人」「人头」「人大」这类组合拼出来却不在本组 3 个词里，程序说「拼不成词」——病根是词库只有 969 条组词（字库「组词」栏派生），查不到这类词。现在**出题侧**多了一张 1734 条常见搭配表当第二道互斥源：硬冲突（拼出词库里另一个词）永不接受，软冲突（拼出搭配表里的词）尽量避开；**避不开就让这组只出 2 个词**，不再靠放宽冲突凑满 3 个。② 词太难也不对，但**难度是相对的**：同一个「统一」，一年级学「一」的孩子看不懂，六年级学「统」的孩子就是正常词（老师 2026-10-29 原话）。所以不再维护固定黑名单，改成按**字的册次**算：每个字换算成教材册次（一上 = 0 … 六下-认 = 21），学生水平取他自己字表册次的中间值，超纲字最多高 4 册；两个字都在字表里的词一律放行。一年级孩子最深只用到「个」这种二上的字，「统」在六上、差 19 册，怎么都碰不到；六年级学「统」的孩子拼「统一」完全正常。③ **判分与文案一律保持原样**：拼不上照旧抖一下、响一次错误音、提示「这两个字拼不成词，再试试」，题面仍是「点两个字，拼成一个词」，语音仍是「再试一试」——老师 2026-10-29 明确「这个就是拼词语，并没有给示例，不是照着拼」「拼错了就抖一下退回来就好」。实测：撞词组随机字表 30.6% → **0%**、超高频字表 83.3% → **0%**（120 组，尺子固定为完整 1734 条）；超纲字按册次卡死——一年级字表出词最深只到二上（「个」），「统」「尺」这类六上的字碰不到；出题量方面随机 20 字表 100% 出满 3 个词，一上那 10 个字的极端字表每组 2~3 个词、**每局照样 4 组**。**v26 还补了「今天练到哪儿」**（T-021）：练完一个题型，结算页给一整行的大按钮「下一个题型：图字配对 →」，顶上一排圆点打勾 + 「已完成 2 / 6，还有 4 个」；最后一个题型做完写「今天的练习全部完成」。进度按「日期 + 学生」记在本机，跨天自动清零，不进云端。**结算页的鼓励语和按钮已经彻底分开**（老师 2026-10-30：「学生等下在那一直点做的不错怎么办，这两个都没有区分开来」）：鼓励语退成透明底的 21px 绿字（`.fb-say`，原来是带底色描边的 `.feedback`，跟按钮长得一样），「下一个题型」是整屏唯一的主按钮（实心深绿 + 白字 + 立体阴影，24px / 76px），孩子不认识字也看得出只有下面那个能戳。

**v27 把听写拆成两个、并在认字乐园加了「笔顺描写」**（T-023）：老师原话「上次让你增加了汉字听写，但是你是词语听写，我建议可以分开来，是两个练习，汉字听写和词语听写。还有，在最开始的全班都可以学习的地方应该增加一个描写，就像练习那样的。而且应该有笔顺才对。笔顺是用灰色底图汉字上的动画变红色来先呈现怎么写，再让学生描写」。① **听写拆成「汉字听写」（只听单字、一个方框）与「词语听写」（听整词、一字一格）**，题型 8 → 9；老学生的题型列表自动补上「词语听写」（`migrateTypes`，幂等，备份到 `wb2_data_v1.bak-T023`），老师可以再取消勾选。词语听写出题前先筛出「组词栏里真有 2~4 字词」的字，一个字都凑不出来时给明确提示，不再是一屏空题。② **学字卡多了「描写这个字」**：打开就是灰底整字，先自动播一遍笔顺——**一笔一笔长出来变红**（`soPaint` 三层：灰底整字 → 已写完的填红 → 当前笔裁到自己轮廓里画粗线，红色不会糊到相邻笔画上），播完整字红着停 0.7 秒再淡回灰底，孩子照着灰字描；上面有田字格、下面是指针笔迹，可以「再看一遍」「写好了」「重来一遍」「写下一个」。**这里不判分、不写学习记录**（没有学生档案也没有手写识别，写好写坏老师看一眼）。③ 笔顺数据：`build/gen_stroke_data.py` 下载 hanzi-writer-data@2.0.1（派生自 Make Me a Hanzi，Arphic Public License）的后 561 个字，坐标 -92~1005 全为整数，用「每个数字 → 2 字符 base36（`v+128`）」压成 **558 KB**（原始 1.20 MB，45.5%），往返校验逐数字无损；产物 14.10 → **14.66 MiB**，仍在本机 16 MB 预算内。④ 踩过的坑：笔顺数据 **y 轴朝上、基线在 900**，而 canvas 朝下，第一版直接照抄导致「上」整字上下颠倒；`soFit` 里改成 `setTransform(dpr*w/1024, 0, 0, -dpr*h/1024, 0, dpr*h*900/1024)`，清屏也要先退回单位矩阵。**这个错 jsdom 测不出来（没有 canvas），只能靠无头浏览器截图发现。**

**v28 把学字卡收拾干净、并把笔顺放慢**（T-023 续）：老师三条原话「不需要什么只看拼音和再听一遍这些词语，你直接在这个字旁边放一个喇叭的标志就好了呀。还有，这个描写的位置很奇怪，这么大个框横在这也不是很好看，给我优化一下这个布局和样式。描写我点进去看了下，速度太快了，学生无法反应」。① **「听一听 / 只看拼音」两个大按钮去掉**，改成汉字右侧一个圆形喇叭（48px，点一下有一圈脉冲回馈）；「只看拼音」整个删掉（`togglePinyinOnly` 一并清理）——想只听不看字就直接点喇叭。② **描写入口不再是一条占满宽度的绿框**：改成「点这个字」——**汉字本身就是按钮**（86px，是这张卡上最大的点击目标，特需孩子不用瞄准），下面一行小胶囊「点这个字，看笔顺照着描」当说明；旧的 `.sheet-wbtn` 整条删掉。③ **笔顺放慢到孩子跟得上**：v27 是一笔 300ms、笔间 0 停顿（`SO_GAP_MS` 声明了却没接进 `seq`），7 笔的「男」2.1 秒就播完；现在是一笔 **640ms（8 帧 × 80ms）+ 笔间停 340ms + 打开先停 600ms**，同一个字 **7.1 秒**，整字红着停的时间从 0.7 秒加到 **1.1 秒**。④ 顺手把 `soPlay` 的序列生成提到画布判断之前——jsdom 没有 canvas，原来「没画布就没有节奏数据」，节奏这条护栏等于形同虚设。门禁 84 → **88 项**（新增四条：只剩一个喇叭、点字进描写不许塞回横框、节奏下限 500/200/400ms、起手用 `SO_START_MS`），测试 620 → **629**。
