### G4 发布后校验（`download_page_artifacts.py --source publish` 拉回线上产物）

**不能直接比对字节/字符串**——平台会给每个元素注入 `data-page-node-id`、给带子节点的元素加 `data-pnid-children`，还会重排属性顺序（`content=... name=...`）。线上文件比本地大 ~22.5 KB 是正常的（v19 实测 22,518 字符）。

正确的判定方法：**抽出 `<style>` 与各 `<script>` 的块内容，逐一比对**。
注意三点：① 正则必须带属性（`<style[^>]*>`），线上会加 `data-page-node-id`；
② 线上会多一个平台注入的 `inject.js` script 块（内容为空）；
③ **两边都要过滤空块再按索引比对**——只过滤一边会导致索引错位，明明内容一样却全报 DIFF（v13 踩过）。

```python
import re
pub = open('build/_verify/生活语文练习台.html', encoding='utf-8', newline='').read()
loc = open('build/生活语文练习台.html',      encoding='utf-8', newline='').read()
sty = lambda t: [x.strip() for x in re.findall(r'<style[^>]*>(.*?)</style>', t, re.S)]
scr = lambda t: [x.strip() for x in re.findall(r'<script[^>]*>(.*?)</script>', t, re.S) if x.strip()]
assert sty(pub) == sty(loc) and scr(pub) == scr(loc)   # 应全部相等
```

- [ ] style 块内容相等
- [ ] 两个 script 块（语音 JSON 4.14 MB / 主逻辑 1.00 MB）内容相等
- [ ] 关键新符号在场（本次 `synthTone` `sfxStreak` `gameFx` `voicePack` `bootMask` `fruitSVG` `basketSVG`）
- [ ] 唯一允许的外链是平台自己注入的 `src="/page/page_comm/inject.js"`

## 二、人工验收（按场景走一遍）

### A. 认字乐园
- [ ] 打开首页就是认字乐园，不是选人页
- [ ] 搜「hu」能出带 hu 拼音的字；搜「老虎」能出「虎」；搜「虎」能出「虎」
- [ ] 点册次 chip，字数量与角标一致
- [ ] 字卡：有图的左边是图；**没图的左边整列消失、字居中**，下方组词是小字
- [ ] 点开字卡后**先静一下**再念字，字念完**停一下**才念组词
- [ ] 「只看拼音」能遮住汉字

### B. 四款游戏
- [ ] 每款都能正常点中、有对错音效、有得分与连击
- [ ] 读题按钮能再听一遍
- [ ] 结算页三星与得分正确，「换个玩法」能换
- [ ] 全程**只需单指点击**，没有需要拖动的操作
- [ ] 玩完游戏后，老师端练习记录**没有**新增（不污染成绩）

### C. 班级练习
- [ ] 点学生照片进入，题量与学生配置一致
- [ ] 每题自动读题**只念一遍**，可点喇叭重听
- [ ] 选对/选错有音效，选错不扣分可重试
- [ ] 「提示一下」「读对了」「跳过这题」都生效且记录正确
- [ ] 结算页正确率、星级、评语正确，报结果不与庆祝音效重叠
- [ ] 练完后老师端进度矩阵有变化

### D. 老师端
- [ ] 长按「老师」1 秒才进（短按不进）
- [ ] 新增学生 + 传照片 + 勾题型 + 勾字组 → 保存后练习页可见
- [ ] 字库筛选/搜索/新增/停用生效
- [ ] 导出备份 → 清空数据 → 导入备份 → 数据完整恢复
- [ ] 断网后页面仍可用（仅同步状态变化）

### E. 移动端
- [ ] 手机宽度下无横向滚动
- [ ] 按钮可点区域 ≥ 50px（特需学生）
- [ ] 输入框字号 ≥ 16px（iOS 不自动放大）
- [ ] iPhone 底部安全区不遮挡操作

## 三、回归红线（任何版本都不能破）

| 红线 | 为什么 |
|---|---|
| 全站零外链 | 学校内网 / 断网必须能用 |
| 数据本机优先 | 云端失败不能丢数据 |
| 游戏不依赖图片 | 图示只有 16% |
| 语音不逐字拼接 | 「小↓手↓」体验极差 |
| 单指点击、无拖拽 | 特需学生手部精细动作受限 |
| 不擅自改 `PACE` / 音色 / 语速 | 用户多次返工才定稿 |
