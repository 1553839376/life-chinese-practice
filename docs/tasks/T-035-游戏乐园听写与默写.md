# T-035 · 游戏乐园加「听写」、描写屏加「默一默」

- **日期**：2026-11-04
- **版本**：v40
- **状态**：已发布（newVersion 28，2026-11-04）

## 一、用户需求（原话）

> 「游戏乐园我想加一个听写模式，差不多是和练习那个地方一样。还有前面的字卡那里描一描我想再加一个默写在里面」

三个口径先问后做（AskUserQuestion，老师选的都是第一项）：

| 问题 | 老师选的 |
|---|---|
| 听写听什么 | **只听单字**（不是整词、不是句子） |
| 写对写错记不记学习记录 | **不记**（保持游戏纯玩，别污染档案） |
| 默写放哪 | **放进描写屏**（描完再默，同一屏两档动作） |

## 二、游戏乐园第六张卡「听写」

### 为什么不是把练习页那个「汉字听写」搬过来

练习页的「汉字听写」是**题型**：进 `stu.types`、写 `STATE.logs`、算掌握度。老师要的是**玩**——
从乐园点进去、挑一批字、写几格，写完全部不记成绩。所以两件事分开实现，只在**手写区**这一层共用代码。

### 实现

| 位置 | 做法 |
|---|---|
| 卡片 | `#gamePick` 第六张 `data-gp="dict"`，`.sg-btn.gd{grid-column:1/-1}` 整行、**实线**（虚线是「随便玩」表示「不算正式玩法」的专用语言） |
| 玩法表 | `GAME_NAMES` 加 `dict: '听写'`；**`GAME_KEYS` 保持四款** —— 听写不进「随便玩」的随机抽取，也不进「换个玩法」轮转 |
| 题面 | `dictScene()`：一行「听一个字，在格子里写下来」+ 田字格 + 操作条。`#scrGame.is-dict` 下 **`.ga-word` 与 `#gameHint` 一律 `display:none`**，否则题目字直接摆在屏幕上 |
| 语音 | `gameSay` 里 `kind === 'dict'` 只返回「听一听，写下来。」+ 那个字（复用已有 `q_dict` 音），不念 `askWord`（那是「找出这个字」的句式） |
| 手写区 | `wgInit(field, 'gDictRow', dictFit())` —— `p5.js` 的 `wgLayout` 新增 `maxSize` 参数，尺寸由 `dictFit()` 按场高算，最多 300 |
| 判分 | 无识别。写完「写好了」→ `dictReveal(false)` 浅绿正确字叠在笔迹下 → 「写对了」`dictOk()` / 「没写好，重写」`dictMiss()` |
| 重写 | `dictMiss()` 只 `GAME.miss++` + `wgClear()` + 恢复操作条，**不结束题目、不判死**（对齐练习页 v22） |
| 计分 | `gameAward()`（v40 新抽出来的唯一入口）：`combo++ / done++`，按 `GAME.miss > 0` 分 `oneTry` / `retried`，`score += 10 + min(combo-1,5)*2`，880ms 后下一题 |
| 记录 | **不写**。`dictOk()` 体内只有 `GAME.locked = true; gameAward();`，不碰 `localStorage` / `STATE.logs`（G1 有护栏） |
| 结算 | 「写了 6 / 6 个……」+「正确率 83% · 得了 90 分」+「有 1 个是重写过的」（v39 的口径原样适用） |

### 窄屏（修了两轮）

390×844 下游戏场只有 **390px** 高：题面 22px + 一句说明 + 田字格 + 操作条要 **413px**，溢出 23px。
`dictFit()` 的预留从 `h - 140` → `h - 172` → **`h - 190`**，再给 `@media(max-width:520px)`
收 `.game-field.g-dict` 的 `gap`（14 → 10）与 `padding`（16 → 12）。
实测 390 下 `scrollHeight == clientHeight == 390`，田字格 200px。

## 三、描写屏第四个按钮「默一默」

描写屏原来是「再看一遍 | 擦掉 | 写好了」三档动作。默写不是「再描一遍」，是**把灰字收走**，
所以做成第四个动作 + 两个新状态：`recite`（默写中）/ `recited`（写完了，对答案）。

| 动作 | 结果 |
|---|---|
| 点「默一默」 | `traceClearInk()` 清笔迹 → `#traceGrid.blind` + `#traceMask.blind` → `#traceMemTag`「默写」小绿标亮 → tip「灰字收起来了，凭记忆写一遍。」→ 按钮换成「再看一遍 \| 擦掉 \| 写好了」，`#traceMem` 自己隐藏 |
| 「写好了」 | `state='recited'` → `#soAns` 亮半透明绿正确字 → 去掉 `blind` 让灰字回来对照 → 只留「下一个字」 |
| 「再看一遍」 | **＝放弃默写**：退回 `trace` 态、灰字放回来重描。不留「写了一半又忘了」的半截状态 |
| 「擦掉」 | 还是清笔迹，状态不变 |

**`blind` 必须藏两样东西**：

1. 格子里的灰字有**两层**（`#soBase` 笔画层 + `.so-ghost` 楷体兜底层），少藏一层就还印着答案；
2. 面板顶上一行 **「木 mù」** 是更大的答案 —— 用 `#traceMask.blind .trace-name b/i { visibility:hidden }`。
   **用 `visibility` 不用 `display:none`**：后者整行塌掉，格子会往上跳一格。

进出都 `traceMemReset()`（`openTrace` / `closeTrace`），否则下一个字一打开就是默写态、灰字还藏着。

**默写不判分、不写学习记录** —— 和描红同一个口径（没有手写识别就不假装判分）。

## 七、踩过的坑

- **听写屏忘了藏 `#gameHint`**：那是「提示一下，缩小范围」的条，选项类玩法里有用，听写里等于
  把答案的偏旁部首写在屏幕上。护栏两条分开判（`.ga-word` 与 `#gameHint`）。
- **`wgInit` 原来只认 `$('stage')`**：游戏场是 `#gameField`，不泛化就只能复制一套画布逻辑。
  加了 `root` 与 `maxSize` 两个可选参数，练习页调用点一个字没改。
- **`GAME.miss` 又是「这题错没过」**：v39 定下的语义直接用，听写重写只 `miss++`，
  不用另开「重写过」字段（云端 schema 也没有这一列）。
- **`display:none` 藏标题会把格子顶起来**：`visibility:hidden` 保留占位才不跳。
- **headless `--window-size=390` 会被钳到 492**：判定溢出要看 `scrollWidth === innerWidth`，
  要验真实 390 排版得把场子 inline 设成 390 宽再量 `scrollHeight vs clientHeight`。
