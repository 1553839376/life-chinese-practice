# T-033 · 同音字不再当干扰项 + 听写加「看一眼」

- **日期**：2026-11-03
- **版本**：v38
- **状态**：已交付

## 一、用户需求（原话）

> 「有个问题，就是听读音找汉字的时候要避免选项出现同音字。刚刚读音读的是和，但是选项有禾、和，学生选错了。另一个就是听写要有个选项是给学生看一眼，然后就关掉的。方便提示一下子想不起来的学生。目前现有的是无法关掉的」

两件独立的事：

1. 听音找字（顺带看拼音写字）的选项里不能出现同音字。
2. 听写要一个「看一眼」：给学生瞄一下答案，然后**自己关掉**。现有的是关不掉的。

## 二、同音字：题目本身有两个正确答案

读 hé，选项里同时有「和」和「禾」——孩子听对了也选不对，因为**声音里真的没有区别**。

判断口径：**去声调的拼音相同就算同音**（`noTone(p)`）。

| 组 | 拼音 | 处理 |
|---|---|---|
| 和 / 禾 / 河 / 合 | hé | 只留目标那一个 |
| 喝 | hē | 也排除（特需孩子分不清声调，靠声调区分等于还在考听力） |
| 绿 / 律 | lǜ | 同一组 |

只对「**听音找字**」「**看拼音写字**」生效；「找一样的字」「图字配对」的线索是字形和实物，同音不构成第二个答案，口径不动。

三层抽取，永远凑够 4 个选项：

1. 学生字表里、读音不同的字；
2. 不够 → 从**全库**补读音不同的字（干扰项是拿来排除的，不是要求孩子认的）；
3. 还不够（不会发生）→ 只能允许同音。

**目标字仍是只从学生字表取**，没有回退全库。

## 三、听写「看一眼」

| 约束 | 值 | 为什么 |
|---|---|---|
| 亮多久 | **3 秒**，按钮倒数「看一眼 3→2→1」 | 不数着数孩子会一直盯着等，到点突然消失反而吓一跳 |
| 看几次 | **每题一次**，之后按钮停在「看过了」并置灰 | 允许连点就等于「关不掉」，退化成抄写 |
| 记什么 | 一次 `promptUsed`（辅助完成） | 看一眼写出来的不该算「独立答对」 |
| 多清楚 | `.peek` → `opacity .88`（判分那次是 .45） | 3 秒里隔着已经写上的笔画，看不清等于没给 |
| 判分时 | 答案不被定时器收走 | 那一步要一直亮着对照（`STATE.quiz.checked` 挡住 tick） |
| 老师入口 | 辅助栏「提示一下」也走这一条 | 同一动作只许一套行为；旧版它是永久亮的 |

描红不加这个按钮：底字本来就在格子里。

## 五、关键约束（别再改回去）

1. **同音判定必须走 `noTone`**：只比裸拼音会把 hé/hē 判成不同音，等于还是靠声调考听力。
2. **只对两种题型生效**：`SAME_SOUND_TYPES` 只有「听音找字」「看拼音写字」。加到「找一样的字」上是错的口径。
3. **目标字不许从全库取**：只有干扰项可以借全库。抽取顺序 ①字表不同音 → ②全库不同音 → ③字表兜底，顺序不能调。
4. **每题只许看一次**：`STATE.quiz.peeked` 在 `resetQState` 里清；不设上限就等于关不掉。
5. **倒计时按钮要保留文字**：写成「看一眼 3」，不要光一个「3」——按钮缩成一小块会被当成坏了。
6. **`wgHint` 里不许再出现裸的 `wgReveal()`**：那是「永久亮答案」的回潮入口，G1 有护栏盯着。
7. **窄屏四按钮必须 2×2**：`flex-wrap` 会折成 3+1；用 `grid-template-columns:1fr 1fr`。
8. **测试里造字表不能用 `CHARS` 直接 assign**：字段是反的（`CHARS.c` 是汉字、`STATE.chars.w` 才是汉字），照搬会得到 0 个字的字表，`startQuiz` 静默 return。
