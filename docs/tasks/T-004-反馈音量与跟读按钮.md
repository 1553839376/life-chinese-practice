## 根因与改法

### 1. 音量
| 位置 | 旧 | 新 |
|---|---|---|
| `VA_SFX_GAIN.gain.value` | 0.9 | 1 |
| `sfxOk` 四音峰值 | .075 / .068 / .062 / .052 | **.26 / .24 / .21 / .18** |
| `sfxNo` 两声 | .05 / .045 | **.20 / .17** |
| `sfxStreak` | .05 / .045 | .18 / .16 |
| `sfxSynth` 兜底 | .03~.07 | .09~.18 |

语音走 `VA_VOICE_GAIN = 1`，音效过去只有它的十分之一 → 教室环境听不见。提响后正确音约为语音峰值的 1/3，不抢话但明确。

### 2. 鱼的动效
动效**没有丢**，是幅度太小（±11px / 4.2s）。现在三件事叠加：

- 鱼身：`translate(-20px,3px) → translate(20px,-13px)` + `rotate ±2.6deg`，3.4s
- 尾鳍 `.fish-tail`：`rotate ±13°`，0.86s，`transform-origin:100% 50%`（根部在身体左端）
- 侧鳍 `.fish-fin`：`rotate -9°~11°`，1.15s，`transform-origin:0 50%`

必须用 `transform-box:fill-box`，否则 `transform-origin` 的百分比按整个 SVG 视口算，转动轴会跑偏。

### 3. 跟读按钮
`认读跟读` 在 `renderStage` 里额外输出 `.read-actions` 容器（大按钮 + 一行提示）。
`bindStage` 绑点击 → `gradeAnswer(true)`；`syncHelpBar` 负责禁用与收起；
`#btnRight` 改为始终隐藏，避免两个「读完/读对」入口并存。
