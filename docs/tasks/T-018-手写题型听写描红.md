# T-018 · 两个手写题型：汉字听写 + 描红汉字

- 建立：2026-10-28
- 状态：**已实施（v25）**
- 来源：用户 2026-10-28 原话「需要增加两个题型，一个是汉字词语听写，给一个方框给学生默写。还有一个是描红汉字」

---

## 一、要解决的两件事

现有 6 个题型全是「点一下选一个」，孩子从没在屏幕上真正写过一个字。
可这个班的教学目标里，「会写」和「认识」是两件事，而平台只测了后者。

| # | 新题型 | 一句话 |
|---|---|---|
| 1 | **汉字听写** | 听一个词，在田字格里默写出来 |
| 2 | **描红汉字** | 田字格里摆一个浅灰楷体字，照着描一遍 |

---

## 二、实施口径

### 2.1 两个题型共用一套画布

- 每格一块 `<canvas>`，`pointerdown/move/up` 手指或触控笔书写，`touch-action:none` 保证写字时页面不跟着滚。
- 按 `devicePixelRatio` 放大画布再 `setTransform` 缩回来，否则高分屏上笔画是糊的。
- 笔迹存成「笔画数组」（`WG.boxes[i].strokes`），**橡皮＝清空重画**，不做 undo（对这群孩子，「擦掉重写」比「撤销一笔」更好理解）。
- 一个孤立的点也画成圆点：点一下就是顿笔，不能凭空消失。
- 方框尺寸由 `wgLayout()` 按行宽算出来写死 px（不用 CSS `aspect-ratio`，教室平板是不是 iOS 15 以上不确定），字号一并定为格宽的 76%。

### 2.2 听写：没有手写识别，所以不假装判分

```
听词 → 写 → 点「写好了」→ 每格浮出浅绿的正确字（叠在笔迹下面）→ 「写对了」/「没写好，重写」
```

- **不接入任何识别**。离线单文件、教室断网，识别做不了；假装判分会直接判错孩子的字。
- 亮答案用「叠在笔迹下面」而不是左右并排：孩子能一眼看出自己哪一笔歪了。
- 「没写好」→ 记一次错 + 清空重写 + 再念一遍词。**一题最多记 1 次错**（同 T-016 口径），重写是给他机会，不该双重惩罚。
- 亮答案后收起「擦掉重写」「再听一遍」：下面已经有「没写好，重写」，两个重写并排必点错。

### 2.3 描红：记辅助，不记独立答对

| 记录项 | 描红后 |
|---|---|
| `n` | **+1**（确实练了一次） |
| `hinted` | **+1** |
| `prompts` | **+1** |
| `alone` | **不变** |

代码上就是把 `STATE.quiz.promptUsed = 1` 后再走 `gradeAnswer(true)`，复用现有记账。
**这是刻意的**：照着描不等于认出来了。若记 `alone`，描两遍就满足 `alone>=3` 进「已掌握」，
老师看着档案以为会了，换个地方还是不认识 —— 档案骗人比没有档案更糟。

### 2.4 出题口径（和老题型不一样的三处）

| 项 | 老题型 | 手写题型 |
|---|---|---|
| 字表下限 | 至少 4 个字（要凑干扰项） | **1 个字也能练** |
| 一次题量 | `stu.count` 3–10 | **最多 6 个**（写字比点选慢一倍） |
| 读题念什么 | 念这个字 | 听写**念整词**（念单字孩子不知道要写两格） |

听写用哪个词：字库「组词」栏的第一个词，只收 1~4 字且确实包含该字的；没有组词就退回听写单字。

## 四、踩过的坑

1. **题干重复两遍**：`.q-head` 里已经用 `TYPE_DESC` 写了一句说明，页面里又写了一句几乎一样的话 → 删掉页内那句。孩子不认字，重复的是噪音不是强调。
2. **按钮顺序**：第一版把「再听一遍 / 擦掉重写」放在「写好了」上面，主按钮被挤到最下面 → 改成「方框 → 大按钮 → 辅助操作」，和跟读页「读完啦，下一个」一致。
3. **check 态两个「重写」并存**：亮答案后 foot 有「没写好，重写」，tools 里还有「擦掉重写」 → check 态把 tools 收起。
4. **jsdom 没有 canvas**：`getContext` 返回 null。所有绘制先判空，结构（几格、几个按钮）必须不依赖画布就能测，否则门禁跑不了。
5. **别用 `aspect-ratio` 兜底尺寸**：靠 `wgLayout()` 算 px，CSS 只给没跑 JS 时的兜底值。
6. **`wgInit` 量宽度要量两次**：首帧字号/滚动条没落定会差几像素，`setTimeout(..., 80)` 再量一次（**不挂 rAF**，后台标签页不执行）。
