## 一、老师的原话

指的是上一轮清单里的第 3 条：孩子练到一半被叫走（下课铃、上厕所、老师叫去别的教室），回来只能从第一个字重来，之前做对的那些白做。

## 二、口径：每翻一题存一次，进今日字卡先问

| 项 | 定法 |
| --- | --- |
| 键 | `wb2_resume_v1`（本机独立键，不进 STATE / 云端 / 学习记录） |
| 存 | `resumeSave()` 在 `nextQuestion()` 里 `i++` 之后；`startQuiz()` 里 `resumeClear()` 紧跟 `resumeSave()` |
| 清 | `renderSummary()` 结算时清、`startQuiz()` 换新题前清、`resumeDrop()` 老师说「不练了」时清 |
| 读 | `resumeLoad(stu)` 只认**同一个学生**、且 `day === todayKey()` |
| 显示 | `resumeBarHTML()` 在今日字卡顶部：「上一轮「听音找字」还有 3 题没练完，接着练吗？」 |
| 两个按钮 | `#btnResumeGo` 接着练 / `#btnResumeNo` 重新开始（`p6.js` 事件委托） |

`resumeGo()` 把存下来的 `qs`（题目 + 选项）原样塞回 `STATE.quiz`，**不重新出题**——重出的话孩子会看到一遍从没见过的题，「接着练」就成了假的。

---

## 三、存什么：只存汉字字符串

```js
{ v:1, stu, type, i, right, prompts, retried, wc:[…w], qs:[{t, o:[…w]}], day, ts }
```

选项和题目都只存 `w`（汉字），恢复时按 `charMap()` 查回完整字对象。这样备份 / 存档不会因为字库字段变动而崩，体积也小。

**拼词语与三个手写题型不存**（`if (!q || !q.target || !q.opts …) return;`）：
- 拼词语的题面是「从 8 个字块里挑两个」，恢复后要把字块位置、已选状态一起重建，结构不一样；
- 手写三题型有画布和笔迹，续练要连笔迹一起存才说得过去，这不在本轮范围。

所以这两类题练到一半离开，回来仍是从头——字卡上那条提示只对「选项类」题型出现。这是**刻意**的，不是漏了。

---

## 四、目标 / 非目标

**目标**：被叫走一次不再白练；回来一眼看到「还有几题」，一键接上。

**非目标**：
- 不做多份存档（一轮只有一份，新的覆盖旧的）。
- 不做跨天续练（`day !== todayKey()` 直接丢，昨天的题今天重出更合理）。
- 不改题型进度 `wb2_sess_v1` 的口径。
