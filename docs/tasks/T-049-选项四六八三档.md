## 一、老师的原话

> 「6）目前学生选项只有四个，希望支持可调控的4/6/8三档难度，主要应用于练习乐园和「听音找字」这类找相同题目，并增加相应的难度切换按钮。」

---

## 二、档位只有一个来源

```js
var LS_OPTN = 'wb2_optn_v1';
var OPTN_SET = [4, 6, 8];
function optnLoad(){ … 非法值 / 没有值一律回 4 … }
function optnSet(n){ … 只认 4 / 6 / 8 … }
```

- 默认 **4**，跟 v52 之前一致——老师不点按钮，课堂行为一字不变。
- **全局一份**，不按学生区分（老师要的是「这一节课用几档」，不是每个孩子一套）。
- `optnCls(n)` 返回 `four` / `n6` / `n8`，**跟实际给了几个走，不跟档位走**：字表只有 5 个字时选 8 档也只能给 5 个，这时按 6 档的网格排（3 列）最舒服。

---

## 三、出题侧：干扰项个数跟着改

| 位置 | 改法 |
| --- | --- |
| `buildQuestions()`（练习 9 题型） | `var want = Math.max(1, optnLoad() - 1);` → `pickDistract(pool, want, t, wide, true)` / `pickN(pool, want, [t])` |
| `gameOpts()`（乐园玩法） | 同上，且**先去重再抽**：删掉了原来「`while (out.length < 4 && pool.length)` 用重复字撑满」——两个字并排摆着一样，孩子一眼就看出题坏了，宁可少给几个 |
| `distractorPool()` | 「同组优先」的阈值从写死 3 改成 `need = Math.max(1, optnLoad() - 1)` |
| `useHint()`（点「提示」） | `var kill = Math.max(2, all.length - 2);` —— 4 档还是删两个，6/8 档删到只剩「目标 + 1 个」 |

**v38 的同音禁令没动**：`SAME_SOUND_TYPES`（听音找字 / 看拼音写字）仍然按 `pyKey = noTone(p)` 排除同音字，6/8 档也一样。这是三条判据里唯一不能为了「凑够 8 个」放宽的。

## 四、布局侧：四款场景各有一套 6 / 8 排布

| 场景 | 4（老基线，一像素不挪） | 6 | 8 |
| --- | --- | --- | --- |
| 戳泡泡 `.bub-wrap` | 老网格 | `n6` | `n8` |
| 钓鱼 `.fish-wrap` | `fishSlots(4)` = `[[3,4,6],[47,27.5,8],[3,51,6],[47,74.5,8]]` | `fishSlots(6)` 3 行 2 列 | `fishSlots(8)` 4 行 2 列 |
| 摘果子 `.fruit-wrap` | 老网格 | `n6` | `n8` |
| 喂小动物 `.feed-plates` | 老四盆 | `n6` | `n8` |
| 练习选项 `.opts` | 2 列 | `.opts.n6` 3 列 / 48px 字 | `.opts.n8` 4 列 / 40px 字 |

`fishSlots(n)` 每项是 `[left%, top%, 横向抖动%]`；`fishScene` 从写死 4 条改成 `for (i = 0; i < slots.length && i < opts.length; i++)`。

**顺手修的老问题**：`.plate`（食盆）原来写死 `padding-top:16px`，碗高 116px，字一直浮在碗沿上方——8 个食盆时最刺眼。改 `padding:38% 0 0`，字落进碗口。

## 五、切换按钮：两处，同一份 HTML

`optnBarHTML()` 生成 `选项个数 [4 个][6 个][8 个]`，`paintOptnBars()` 同时刷 `#optnBar`（练习页，题型进度条下面）和 `#optnBarLearn`（乐园选玩法页最上方）。

- 练习页：预习态（`preMode(true)`）隐藏，做题时才出现。
- 乐园：进 `renderLearn()` 时刷一次。
- 点击走 `p6.js` 事件委托 `[data-optn]` → `optnChanged(n)` → `optnSet()` + 重绘 + 一句 toast（「以后每道题给 6 个选项（字表太小时会少给几个）」）。

---

## 六、目标 / 非目标

**目标**：一节课想简单点就 4 个、想加难度就 6 / 8 个；两处入口都能改，改完立刻生效。

**非目标**：
- 不动同音禁令、不动 `PACE` / `PACE_GAP`（节奏是敏感参数，先问再改）。
- 不加「2 个」「10 个」——老师指定三档。
- 不按学生存（不做每人一套难度）。
