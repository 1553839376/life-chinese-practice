## 二、根因：不是判分错，是分母恒等于答对数

- v22 起「答错可重试」：点错不判死，只把那个选项灰掉（`.opt.miss`），孩子最后每题都会点对。
- 旧 `build/p5.js` → `renderSummary()`：

  ```js
  var rate = denom ? Math.round(right * 100 / denom) : 0;
  ```

  `right` 最终总等于题数 → **必然 100% + 三星**。v39 当时只补了一行「其中 N 题是试了再答对的」，数字没降。
- 对比 `build/p7.js` → `gameOver()`（v39 已改）：`one = GAME.oneTry; rate = Math.round(one * 100 / total)`。
- 历史注释曾写「**练习结算页刻意不跟**（那边「重试不扣分」），两处不同口径，别顺手统一」——这条约定由本任务作废，`.workbuddy/memory/MEMORY.md` 同步改掉。

## 三、目标 / 非目标

**目标**：练习结算页的正确率、星数、鼓励语都跟「这题错没错过」挂钩，跟游戏乐园同一把尺；结算页把口径写给老师看。

**非目标**（守住范围，别顺手改）：
- 不动出题、`levelOf()`、`syncActive()`、在学名单、跨天掌握（v50）。
- 不动 `gameOver()` / 游戏乐园的 v39 口径。
- 不动学习记录、云端 schema、导出导入；`retried` 只在 `STATE.quiz` 内存里。
- 不改节奏 `PACE` / `PACE_GAP`（用户敏感参数，先问再改）。

## 四、实现口径

| 项 | 定法 |
| --- | --- |
| 正确率 | `oneTry = Math.max(0, right - (z.retried \|\| 0))`；`rate = Math.round(oneTry * 100 / denom)` |
| 分母 | 保留原逻辑：普通题型 `denom = z.i`；`拼词语` 按 `z.qs[i].words.length` 累加 |
| `retried` | `gradeAnswer()` 里 `if (STATE.quiz.wrongLogged) STATE.quiz.retried = (STATE.quiz.retried \|\| 0) + 1;`，一题最多一次 |
| 什么算「试过」 | 点错选项（`missOption`）、连错 2 次看答案、听写「没写好，重写」（`logWriteMiss`）都置 `wrongLogged`；跳过 / 没答完仍算没对 |
| 星数 | `rate >= 90 ? 3 : (rate >= 70 ? 2 : (rate >= 40 ? 1 : 0))` |
| 鼓励语 | `if (allDone && rate >= 90) msg = '太棒了！'`；全题型练完仍显示「今天的练习全部完成」，但低分不硬夸 |
| 结算提示 | `其中 N 题是试了再答对的，不计入正确率` |

**改动分片**：`build/p5.js`（`renderSummary()` 三处）、`build/smoke2.js`（§44）、`harness/run_gate.py`（G1 八条护栏）、`harness/manifest.json`（登记 `oneTry` / `pickOption`，`smoke2.min_cases` 877 → 895）、`build/p4.js` `APP_VER` 与 `build/p2.html` 角标 → v51。

## 五、验收

- `build/smoke2.js` §44 **18 条**：8 题全一次点对＝100%/三星；错 3 题再点对＝**63%/一星**（老师说的那种情况）；不再夸「太棒了」；提示写明不计入正确率；全试过＝0%/零星；跳过＝5/8＝63%；只错 1 题＝88%/两星；单题型完成提示照旧但低分不硬夸；拼词语按词 6/9＝67%；真实 `missOption()` → `gradeAnswer(true)` 路径到结算＝0%；`retried` 不落库。
- `harness/run_gate.py` G1 八条护栏，其中两条是**防回潮**：不许出现 `Math.round(right * 100 / denom)`、游戏侧 `gameOver()` 口径不许被顺手改坏；另一条盯住 `wrongLogged` 的两处置位 / 每题复位 / `missOption` 靠它挡重复记账。
- **符号登记口径**：`manifest.json` 的关键符号表只认 `function/var/const/let` 声明或 `id="X"`。`wrongLogged` 是 `STATE.quiz` 的属性、不能登记（首跑判红），改登记同一条重试链上真有声明的 `pickOption()`；属性的行为由上面的 G1 护栏与 §44 测试覆盖，不靠符号表。
- `python harness/run_gate.py` 全绿；`python build/check_docs.py` 版本号 / 角标 / 变更日志条目一致。
