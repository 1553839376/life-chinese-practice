# T-022 手写题型的语音补齐（整句合成，别再逐字拼）

- 提出人：老师（2026-10-30）
- 状态：已实现（v26，本地构建通过、门禁全绿，未发布）

---

## 一、老师原话

> 「最近改的很多都没有语音，准备在这个电脑上重跑豆包。之前让你加的题型也要重做一下语音，你是单字组合的很奇怪。」

> （给密钥时补充）「本来就不用你全部重跑，只需要要把在这台电脑上增加的新的语音用原来的语音模型合成就好了，还是之前那个声音」

## 二、查出来是什么问题

写了个探针（`build/_probe_voice.js`）把 8 个题型的题面、4 个游戏口令、全部反馈句都过一遍
`sayParts()`——这是真正决定「教室里听到什么」的函数，不是看代码里有没有写这句话：

| 文案 | 实际拆成 | 结果 |
|---|---|---|
| `听一听，写下来。` | 7 段：听／一／听／写／下／来 | 一字一顿 |
| `照着描一遍。` | 5 段，其中**「照」「遍」不在 701 个单字录音里** | **这句根本没有声音** |
| `写好了！`（描红答对） | 2 段：写 + 好了（`w597d4e86`） | 半句人声半句拼 |
| 其余 11 句 | 整句录音 | 正常 |

**病根不是"漏录"这么简单**：这个项目「加一条语音要改三处」（`gen_doubao_voice.py` 的 `SENTS` →
`p_voice.json` → `p8.js` 的 `SENT_FULL`）。v25 加两个手写题型时只写了代码，三处一处没动；
而 `sayParts()` 对找不到整句的文案会**静默回退成逐字拼**（`textParts()` 从长到短找 3/2 字词录音，
再退到单个字），所以表现不是"完全没声"，而是"一个字一个字蹦"，只有生僻字才彻底没声。

## 三、改了什么

1. **`build/gen_doubao_voice.py` 的 `SENTS` 加 4 句**（都用同一个音色：`zh_female_zhixingnv_uranus_bigtts`，`speed_ratio 0.85`）：

| 键 | 文案 | 用途 |
|---|---|---|
| `q_dict` | 听一听，写下来。 | 汉字听写题面 |
| `q_trace` | 照着描一遍。 | 描红汉字题面 |
| `fb_write` | 写好了！ | 描红答对反馈 |
| `sess_all` | 今天的练习全部完成。 | 全部题型练完（原来只有屏幕大字，没声音） |

2. **`build/p8.js` 的 `SENT_FULL` 同步登记这 4 条**，顺手补上一直漏登记的 `g_start`（`准备好啦，开始吧。`）。
3. **`build/p5.js` `renderSummary()`**：全部练完时念 `今天的练习全部完成。`，屏幕上的鼓励语仍是「太棒了！」。
4. **`build/pack_doubao_voice.py` 加增量模式 `DOUBAO_MERGE=1`**：只编码 `p_voice.json` 里没有的键，
   老条目原样保留（不解码、不重编码）。原来的脚本要求 1691 个 WAV 全在，而 WAV 母版只留在原来那台机器上，
   全量重打包在这台电脑上根本跑不了；全量重跑也不划算——同一音色再合成一遍，音质不会更好。

## 四、执行与结果

```
DOUBAO_APPID=… DOUBAO_TOKEN=… ONLY_KEYS=q_dict,q_trace,fb_write,sess_all python gen_doubao_voice.py
VERIFY=1 ONLY_KEYS=… python gen_doubao_voice.py     # 时长自检
DOUBAO_MERGE=1 python pack_doubao_voice.py
python build_html.py
```

- 生成 **4 条 / 0 失败 / 3 秒**；时长自检 **4 条 0 异常**
  （听一听 2.08 s、照着描 1.37 s、写好了 1.17 s、练习全部完成 2.30 s）
- 增量打包：**旧的 1691 条逐条比对，0 条被改动**；语音包 1691 → **1695 条**（701 单字 + 972 整词 + 22 指令句），
  体积 12.85 → **12.90 MB**，单文件 14.73 → **14.78 MB**（预算 16 MB）
- 试听文件：`build/试听-新增4句.wav`（4 句连播，中间留 0.6 s）

## 五、加了两道护栏（这类问题不许再复发）

| 关口 | 断言 | 抓什么 |
|---|---|---|
| G1 | `SENTS` 每句都在 `p_voice.json` 里 | 加了句子忘了生成 |
| G1 | `SENTS` 每句都在 `SENT_FULL` 有映射（按去标点口径比） | 生成了音频但代码里没登记，等于没录 |
| G1 | `SENT_FULL` 指向的键都在语音包里 | 指向不存在的音频 |
| G1 | 代码里写死的题面句（`{ t: '…' }`）都登记过 | 新题型加题面时漏登记 |
| smoke2【27】 | 每句题面/口令/反馈过 `sayParts`，断言**只拆出 1 段且是整句录音**，且用到的音频都在包里 | 逐字拼、生僻字无声 |

护栏先写、先红：补语音之前实测 G1 3 条红、smoke2【27】6 条红，补完才全绿。
门禁 69 → **73 项**，测试 539 → **576 项**（smoke2 370 → 407）。

## 六、留下的

- 老师自己「收进词库」的自建词**没有整词录音**，拼词语念到它仍会逐字拼。目前只在自建词上出现，
  内置 969 条组词全覆盖；真要解决得给自建词也补 TTS（还要处理词库随时增删的情况），先不做。
- 想换音色或语速时才是「全量重跑」的场景（1695 条，约 20 分钟），`SENTS` 里改 `VOICE`/`SPEED` 即可。
