# T-038 · 结算页把「没认出来的字」列出来

- **日期**：2026-11-05
- **版本**：v45
- **状态**：本地已完成、门禁全绿，**未发布**

## 一、起因

老师原话：

> 「现在的效果可以了。然后凡是这种找字的游戏包括几个小游戏和后面的听音找字，最后的结算页面要把错的字列出来」

（第一句是对 v44 钓鱼收线的确认，这一轮要改的是结算页。）

原来两处结算页都只说数字：游戏乐园写「正确率 83% · 得了 90 分 ＋ 找到 6 / 6 个，有 1 个是试了才找到的」，
班级练习写「67% ＋ 三颗星 ＋ 其中 2 题是试了再答对的」。**数字告诉老师「差」，但没告诉他「差哪几个」**——
想补练还得回档案页一个个翻。老师要的就是「这一块字，下次重点练」。

## 二、口径（三条，先定死再动手）

1. **记目标字，不记干扰项**。孩子点错「男」、题面要的是「人」——他没认出来的是「人」。
   把「男」列给老师毫无用处（那只是个随机干扰项，下一次出题根本不会再出现）。
2. **同一个字只列一次**，最多 12 个（一屏放得下，且一局最多也就 6~8 题）。
3. **全对时不出现这一块**，也不写「没有错字」凑数——空着比一句废话干净。

## 三、改了什么

| 文件 | 改动 |
|---|---|
| `build/p4.js` | 新增 `WRONG_LIST_TYPES = { '听音找字': 1 }`（**唯一开关**）与 `wrongBodyHTML(list, label)`（**唯一组件**：按 `c.w` 去重、`n < 12` 截断、没字返回 `''`） |
| `build/p7.js` | `startGame()` 里 `GAME.wrongs = []`；`gameAward()` 里 `if (GAME.miss > 0)` 时把 `GAME.queue[GAME.i]` 推进去（去重）；`gameOver()` 在 `.go-note` 之后插 `.wrong-box`，文案按 `isDict` 分「没写好 / 没找出来」 |

## 四、为什么复用 `GAME.miss` 而不新增字段

`GAME.miss` 在 `gameQuestion()` 里每题清零，天然就是「这一题错过没有」，v39 用它算正确率。
`gameAward()` 里读它一次，顺手把目标字记下来，**不需要再加一个「这题错了没」的平行状态**。
练习侧同理：`STATE.quiz.wrongLogged` 已经是「这题记过错没有」，`wrongChars` 挂在同一个分支里，
`alone + hinted + wrong === n` 那条不变量一点没动。

## 五、踩到的点

- **窄屏会被挤出屏幕**：`.game-over` 原来是 `justify-content:center`，390 的场上只有 312px 高，
  多出一块 60px 的错字条之后标题被顶到可视区外（`align-items:center` 的经典裁顶）。
  改 `justify-content:safe center` + `overflow-y:auto`——内容装得下时仍然居中，装不下就从顶上开始排、可以滚。
- **不要顺手把分数也改**：v39 那把尺（一次就对才算对）是老师特意定的，这一轮一个字没动；
  错字列表只是「多一块」，不改分数、不改星、也不影响 `.go-note`。
- **练习结算页刻意不跟游戏同口径**（v39 就分开了）：练习是「重试不扣分、只补一行」，
  游戏是「点错过就不算对」。这一次列错字两边一样，但**判分口径仍然不同**，别顺手统一。

## 六、验收

- 门禁 167 → **174 项**（七条 v45 护栏，`harness/run_gate.py`）：
  组件唯一 / 开关唯一 / 两处结算都调它 / 游戏侧记目标字 / 练习侧记 `q.target` 且一题一次 /
  按局按轮清零 / 错字卡片有样式且窄屏收一档。
- 测试 892 → **927 项**，smoke2 721 → **756**（新增 §38 共 35 条）：
  ① 钓鱼局点错「男」→ `GAME.wrongs` 里是「人」不是「男」→ 结算出现 `.wrong-box`，卡片是「人 rén」；
  ② 换一局全对 → `GAME.wrongs` 清空、结算里没有 `.wrong-box`；
  ③ 听音找字点错「山」→ `wrongChars` 是「水」→ 结算列出「水 shuǐ」；
  ④ 描红汉字手动塞 `wrongChars` 也不列（开关只开听音找字）；
  ⑤ `wrongBodyHTML` 去重 / 跳过空字 / 上限 12 / 空表返回空串。
- 实测文案：找字游戏「这几个字没找出来，再看看」、听写「这几个字没写好，再看看」、
  听力练习「这几个字没听出来，再看看」。
