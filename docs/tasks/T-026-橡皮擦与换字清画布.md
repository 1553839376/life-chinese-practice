# T-026 · 擦掉看得见 + 换字清画布（v32）

> 提出：2026-11-02　交付：2026-11-02　版本：v32
> 关联：`T-023`（笔顺描写的来源）、`T-024`（描写入口图标，卡面同一套图标语言）

## 一、老师原话

> 「刚刚试了下，发现几个小问题。1.学生认字乐园里的字的描红，没有擦掉，只有写完才能擦掉。我建议放一个橡皮擦的按钮，让学生知道可以擦掉。同理那个学生练习里的描红和听写都最好把擦掉前面加一个橡皮擦的标志便于理解。还有个问题，就是我在一个汉字描红写了字，没擦掉，这个就会出现在我点开另一个汉字的画布，这个需要打开另一个汉字进行一个重置画布。」

## 二、三条要求，各自的病根

| # | 老师说的 | 病根 | 改法 |
|---|---|---|---|
| 1 | 「没有擦掉，只有写完才能擦掉」 | `#traceAgain` 带 `hidden`，只有 `traceDoneTap` → `traceButtons('done')` 之后才放出来。描写中屏幕上根本没有可点的擦除 | `traceButtons()` 里 `again.hidden = false` 恒定；文案在 `.traceAgainTx` 上按状态切「擦掉 / 擦掉重写」 |
| 2 | 「把擦掉前面加一个橡皮擦的标志」 | `擦掉重写` / `擦掉重描` 是纯文字，孩子不认字就只能靠老师念 | 新增 `.ico-i` 线稿图标（倾 40° 圆角矩形 + 套箍竖线）与 `ICO_ERASE` 常量，乐园与两个手写题型共用一个图形 |
| 3 | 「在木上写了字，会出现在大的画布上」 | 笔迹层从 v27 起就是同一块 canvas + 同一份 `TRACE.box.strokes`。`openTrace` 换了字没清数组，`traceLayout` 重设画布尺寸后又把旧笔迹重绘上去 | `openTrace` 开头先 `traceClearInk()`，再改 `#traceChar` |

## 三、实现要点

### 1. 擦掉常显 + 文案两档（`p_so.js`）

```js
function traceButtons(state){
  var replay = $('traceReplay'), done = $('traceDone'), again = $('traceAgain'),
      next = $('traceNext'), tx = $('traceAgainTx');
  if (!replay) return;
  replay.hidden = false;
  done.hidden = (state === 'done');
  if (again) again.hidden = false;              /* v32：任何时候都能擦 */
  if (tx) tx.textContent = (state === 'done') ? '擦掉重写' : '擦掉';
  if (next) next.hidden = (state !== 'done');
}
```

空格子上点「擦掉」不再假模假样说「擦掉了」：

```js
function traceAgainTap(){
  var had = !!(TRACE.box && TRACE.box.strokes && TRACE.box.strokes.length);
  TRACE.state = 'trace';
  traceClearInk();
  if (had) setHTML($('traceTip'), '擦掉了，慢慢再来一遍。');
  else { sfxTap(); setHTML($('traceTip'), '格子里还没有字，直接写就好。'); }
  traceButtons('trace');
}
```

### 3. 换字清画布

```js
function openTrace(c){
  if (!c || !c.w) return;
  TRACE.c = c;
  TRACE.state = 'demo';
  TRACE.done = false;
  traceClearInk();                        /* 必须在改字之前 */
  $('traceChar').textContent = c.w;
  ...
```

顺序的意义：清完重绘的是空白，随后 `soPlay` 才重画灰底，中间不会闪出上一字的残影。

练习里的听写 / 描红**不需要额外处理**——每题 `renderDictation` / `renderTrace` 都重建 `#stage` 的 DOM，`wgInit` 拿到的是新画布与新 `WG.boxes`。

## 五、踩的坑

1. **结构测试只能证明数组被清空，证明不了屏幕上干净**。`TRACE.box.strokes.length === 0` 在 jsdom 里永远成立（没有 canvas），而老师看到的是像素。所以另写了 `_probe_v32.py`：在真 canvas 上用 PointerEvent 画一笔 → 换字 → 读 `TRACE.box.strokes.length` 并把结果写进 `document.title`（`--dump-dom` 读出来），同时截图肉眼确认。
2. **无头 Chrome 截不到「正在写」的中间态**，只能截最终帧；所以验证换字用的是「先画完 → 再换字 → 截新字」这条顺序，正好对应老师报的现象。
3. 图标是**两份拷贝**（p2.html 静态 + p5.js 常量）：第一版只在 p2 里加了 SVG，练习页那两个按钮还是纯文字。这种「同一图形两处上线」最容易漏，已进 G1 护栏。

## 六、遗留

- 描写屏没有「撤销上一笔」，只有整体擦掉。笔迹是笔画数组（擦除＝清空），要做撤销得改成「弹出一笔」；孩子写到一半点错更可能需要它，等老师反馈再说。
- 橡皮擦图标目前 17px，跟 15px 按钮文字等高偏大一档；如果老师觉得看不清，直接调 `.ico-i{width/height}` 即可，两处共用同一个类。
