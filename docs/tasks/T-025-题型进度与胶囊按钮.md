## 一、老师原话

> 「这两个地方的样式需要修改。首先第一页这个方框去下一个体形很长也很生硬很奇怪啊很丑。第二张图片是为了让学生直观了解自己的任务。你这个题型一多就换行很奇怪啊。而且这个圈圈打勾也难理解，能不能正在文字下面呈现一个圈圈，然后用横线连接，如果说完成了这个圈圈就填满或者其他的方式这，总之应该是好看且适配上面题型的文字，不应该这么割裂」

配两张截图：① 结算页（100% + 三颗星 + 「太棒了！」+ 一条整屏宽的深绿按钮 + 两个小按钮）② 练习页顶部（9 个题型名折成 8+1 两行 + 下一排「1 ✓ 3 4 5 6 7 8 9」号码圈 + 「已完成 1 / 9 个题型，还有 8 个」）。

## 二、两条要求，各自的病根

| # | 老师说的 | 病根 | 改法 |
|---|---|---|---|
| 1 | 方框「很长也很生硬很奇怪啊很丑」 | `width:100%` + 76px 高 + 24px 字 + `border-radius:22px`，在 1080px 的题目区里是一条横贯整屏的深绿板子；跟上面圆圆的百分比、星号、纯文字鼓励语不是一套语言；「下一个题型：图字配对 →」整行同字号，看不出哪个是名字 | `inline-flex` + `border-radius:999px` 的胶囊，宽度跟着字走；里面 15px 半透明小字「下一个题型」+ 22px 粗体题型名 + SVG 箭头 |
| 2 | 「题型一多就换行」「圈圈打勾难理解」「不应该这么割裂」 | 两套东西：上面 `flex-wrap` 的带框题型名（9 个折成 8+1），下面另一排号码圈。孩子要在一排名字和另一排数字之间自己做对应 | 圆点搬进题型条目内部，长在名字正下方；每格画一段横线、格子首尾相接拼成一条通到底的线；完成态**填满**而不是打勾；题型条改等宽网格，不再折行 |

## 三、实现要点

### 1. 题型条：一个 `button` 里「名字 + 轨道」

```js
/* p5.js renderTypeTabs() */
sess = sessEnsure(s);
html += '<button type="button" class="type-tab' +
          (k === STATE.curType ? ' on' : '') + (sess.done[k] ? ' done' : '') +
          '" data-type="' + esc(k) + '">' +
          '<span class="ts-name">' + esc(k) + CLOSE('span') +
          '<span class="ts-track"><i class="ts-dot"></i>' + CLOSE('span') +
        CLOSE('button');
```

类名仍然是 `.type-tab` —— 点击委托（`p6.js` 的 `el.closest('.type-tab')`）和几条老断言都靠它，改名只会白添连带改动。

### 2. 连线不加 DOM：每格自己画一段

```css
.type-tabs{display:grid;grid-auto-flow:column;grid-auto-columns:minmax(0,1fr);align-items:end}
.type-tab{display:flex;flex-direction:column;align-items:center;gap:7px;border:0;background:none}
.ts-track{position:relative;display:block;width:100%;height:20px}
.ts-track::before{content:'';position:absolute;left:0;right:0;top:9px;height:2px;
  background:var(--line2);border-radius:2px}
.type-tab.done .ts-track::before{background:var(--green-line)}
.type-tab:first-child .ts-track::before{left:50%}   /* 线从第一个圆点起 */
.type-tab:last-child  .ts-track::before{right:50%}  /* 到最后一个圆点止 */
.ts-dot{position:absolute;left:50%;top:0;width:20px;height:20px;margin-left:-10px;
  box-sizing:border-box;border-radius:50%;background:var(--card);border:2.5px solid var(--line2)}
.type-tab.done .ts-dot{background:var(--green);border-color:var(--green)}
.type-tab.on .ts-dot{border-color:var(--blue);box-shadow:0 0 0 4px var(--blue-bg)}
```

`grid-auto-flow:column` + `minmax(0,1fr)` 是「绝不折行」的关键：9 格等分容器宽度，
相邻格之间没有间隙，所以各格自己的那一段线自然接成一条。

### 3. 颜色顺序有讲究

```css
.type-tab.done .ts-name{color:var(--green)}
.type-tab.on   .ts-name{color:var(--blue)}   /* 写在 .done 后面 */
```

刚做完的那一个同时带 `done` 和 `on`。同优先级后写者胜，所以 `.on` 写在后面 →
此时显示蓝色「你现在在这儿」，而不是绿色「已经过去了」。

### 4. 窄屏：先收字号，再分行

```css
@media (max-width:820px){ .ts-name{font-size:14px} }
@media (max-width:700px){ .ts-name{font-size:13px} }
@media (max-width:660px){
  .type-tabs{grid-auto-flow:row;grid-template-columns:repeat(3,minmax(0,1fr));row-gap:12px}
  .ts-name{font-size:14px}
  .type-tabs .type-tab:nth-child(3n+1) .ts-track::before{left:50%}
  .type-tabs .type-tab:nth-child(3n)   .ts-track::before{right:50%}
}
```

三行版要按 `3n+1` / `3n` 切线段 —— 只用 `:first-child` / `:last-child` 的话，第二、三行
的第一个格会留半截线戳到屏幕左边。

### 5. 结算页胶囊

```html
<button type="button" class="primary next-type" id="btnNextType">
  <span class="nt-k">下一个题型</span>
  <span class="nt-v">图字配对</span>
  <svg class="nt-ar" viewBox="0 0 24 24"><path d="M4 12h14M13 6l6 6-6 6"/></svg>
</button>
```

```css
.next-type{display:inline-flex;align-items:center;gap:10px;
  margin:20px 0 4px;padding:14px 28px 14px 30px;min-height:62px;
  font-size:22px;font-weight:800;border-radius:999px;border:0;
  background:var(--green);color:#fff;box-shadow:0 4px 0 #245741;max-width:100%;white-space:nowrap}
```

箭头用 SVG 不用「→」字符：字符在不同字体里大小和基线都不同，拼进胶囊会歪。
`.sum-actions` 加 `text-align:center`，`inline-flex` 才会居中。

## 五、踩的坑

1. **护栏被自己的样式骗了**：判「不许整行」写了 `'width:100%' not in css`，结果 `.next-type` 里的
   `max-width:100%` 命中，门禁平白红一条。改成 `re.search(r'(?<!-)\bwidth:100%', css)`。
2. **取函数体的窗口开小了**：`html.split('function renderTypeProg')[1][:300]` 还没走到末尾那句
   `renderTypeTabs();`（函数体约 600 字符），护栏假红。
3. **改文档把标题改没了**：Edit 的 `old_string` 写了 `---` + `## 关键坐标`，`new_string` 忘了带回标题，
   表格一度没有章节标题。动结构性文档后要 `grep '^## '` 核一遍。
4. **不要用「缩字号硬挤」解决折行**：第一版只把字号从 16 收到 13，640px 下 9 个名字几乎连成一串
   （格宽 67、名字 52，只剩 7.5px 呼吸）。真正的解法是等宽网格 + 明确的分行断点。

## 六、遗留

  推进，孩子不需要点名字；如果老师反馈「点不动」，再给 `.ts-name` 加一层淡底色。
- ≤660 的三行版会把练习页顶栏撑高约 100px（桌面不受影响）。
