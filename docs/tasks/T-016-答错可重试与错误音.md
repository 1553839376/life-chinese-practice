## 二、实施口径（方案卡里「建议」的落地版本）

### 2.1 答错可重试

```
点错 → 该选项变灰（.miss）+ 抖一下 + 错误音 → 其余选项仍可点，题不结束
点对 → 正常反馈（答对了 / 音效 / 自动下一题）
连错 2 次 → 正确项亮一下（.glow，复用游戏里的 glowPulse）+ 念一次正确读音
```

- **不念答案、不结束题目**：点错只是"这条路不通"，不是"这题完了"。
- **连错 2 次才给答案**：这时"测"已经失败了，目的改成"教会他"，所以视觉高亮 + 听觉各给一遍。

### 2.2 记录口径（这是最容易算歪的地方）

| 情况 | 旧口径 | 新口径 |
|---|---|---|
| 一次点对 | `n+1, alone+1` | 不变 |
| 用提示后点对 | `n+1, hinted+1, prompts+promptUsed` | 不变 |
| 点错一次再点对 | `n+1, wrong+1`，这题结束 | `n+2, wrong+1, alone+1, retry+1` |
| 连错 2 次再点对 | 同上 | `n+2, wrong+1, alone+1, retry+1`（**宽松：一题最多记 1 次错**） |
| 点错后跳过 | `n+1, wrong+1` | 不变 |

三条决定：

1. **一题最多记 1 次错**（方案卡建议的宽松口径）。重试的目的是"给他机会"，不该双重惩罚。
2. **`n` 在第一次错时 +1、终局答对时再 +1**。一题错了再对，确实练了两次（一次错、一次对），所以 `n=2`。
   - **不变量仍成立**：`alone + hinted + wrong === n`（smoke2 有断言钉着，改了会红）。
   - 若一题只错没答对就跳过：`n=1, wrong=1`，也成立。
3. **重试后答对算 `alone++`**（没用提示）。但 `wrong` 也 +1，所以「每次都错一次再对」的字会停在「练习中」而不是「已掌握」。
   - 这是**刻意的**：每次都靠试出来的字还不算稳，继续留在在学名单多练几次，对这个孩子是好事。
   - `levelOf` **一行没改**（方案卡明确要求保持 `alone>=3 && wrong<=1`）。
4. **新增 `retry` 字段**（自纠成功次数），只作档案参考，**不参与 levelOf 判定**。

### 2.3 结算页

`rate` 仍按「最终答对 ÷ 总题数」（`right/denom`），不给重试扣分——结算页是给孩子看的激励，不是考核榜。
但**多一行 11.5px 灰字**：`其中 N 题是试了再答对的`（仅 N>0 时显示），让老师一眼看到"这轮是靠试出来的"。

### 2.4 错误音

```js
/* 旧 */ synthTone(392.00, t,        0.13, 0.20, 'sine',     349.23)
        synthTone(261.63, t + 0.12, 0.22, 0.17, 'sine',     233.08)
/* 新 */ synthTone(415.30, t,        0.14, 0.32, 'triangle', 349.23)
        synthTone(277.18, t + 0.13, 0.20, 0.30, 'triangle', 233.08)
        synthTone( 98.00, t + 0.30, 0.26, 0.26, 'sine',      82.41)   ← 新增低频"咚"
```

- 音量 0.20/0.17 → **0.32/0.30/0.26**，全部 ≥ 正确音峰值 0.26，方向纠正过来。
- `sine` → `triangle`（同响度更"扎"，高频泛音多，教室后排更容易听见）。
- 末尾加一个 98 Hz→82 Hz 的短"咚"：低频穿透力强，和正确音的"明亮上行"在**音区和走向**上同时拉开。
- **总线不动**（`VA_SFX_GAIN = 1`），按既有约定只用每个音的 `vol` 控力度。
