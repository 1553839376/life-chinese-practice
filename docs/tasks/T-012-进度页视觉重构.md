# T-012 · 进度页视觉重构（先看图，再读数）

- 日期：2026-10-23
- 版本：v17
- 触发：用户原话「这个进度管理的界面特别丑，也不清晰，感觉都堆在一起，不够可视化，还有一大堆的解释文字特别显眼」

## 一、旧界面到底「丑」在哪（对着截图逐条拆）

改之前截图 `build/_shots/v17-进度页/old-v16.png`：

| 用户的话 | 实际是什么 |
|---|---|
| 都堆在一起 | 顶部 6 张**同款**数字卡（学生人数/字表总字数/已掌握/需巩固/待学/今天练过），字号、边框、留白完全一样，眼睛没有落点 |
| 不够可视化 | 全班层面只有数字，没有比例；学生行里的进度条只有 **9px** 高、122px 宽，看不出谁掉队 |
| 特别丑 | 卡片里塞三行字（大数字 + 标签 + 灰色小注「答错 3 次还没对过」「全班字表加起来」），信息密度高但层级乱 |
| 解释文字特别显眼 | 标题下面一整段 14px 灰字「分母是每个学生自己字表里的字，不是字库总数。全班共 34 个字次，22 个已经练过。」——比数据还抢眼 |

## 二、改法

**先看图，再读数**，信息分三层：

1. **头图（progStats）**：左边一圈 —— 全班掌握率 35%，环的弧长就是比例；右边一条四段横条 + 四个带数字的图例（已掌握 12 / 练习中 8 / 需巩固 2 / 待学 12），下面三个小胶囊（3 个学生 · 34 个字 · 1 人今天练过）。
   - 圆圈、横条、图例用的是同一套四态配色，看哪都一样。
2. **每个人一行**：头像 + 名字（下面一行 11.5px 只写「今天/昨天/3 天前练过」）+ 12px 四段条（占满剩余宽度，掉队的一眼就短）+ **22px 大号百分比** + 档案按钮。
3. **两个列表**：全班卡住的字（≥2 人）做成大字号红框 chips；今天先抽谁保留「需巩固/靠提示」计数和人名 + 一键抽练。

**解释文字的处理**：

| 原来 | 现在 |
|---|---|
| 14px 灰字长段（分母口径 + 全班字次） | 删除；口径缩成标题旁 11.5px 的 `.prog-note`「分母＝各自的字表」 |
| 卡片里「答错 3 次还没对过」「全班字表加起来」 | 删除，标签已经说清 |
| 「还没有两个孩子同时卡住的字。单人卡住的字在下面…」 | 缩成一个 `.prog-empty` 胶囊「暂时没有」 |

## 三、实现要点

- `p6.js`：新增 `ringHTML(rate)`（SVG 圆环，`stroke-dasharray` 按百分比算，`r=52`，周长 326.7）、`stackHTML(p)`（四段横条，全班/单人共用）；`renderProgress` 重写为「头图 → 每人一行 → 卡住的字 → 今天先抽谁」，并补了没有学生时的空态。
- `p1.html`：删掉 `.stat-cards` / `.stat` 死样式；新增 `.prog-hero / .ring* / .stack* / .slg / .hp / .prog-note / .prog-empty`，`.prow` 从 6 列改 4 列，`.prog-mini` 由 122px 定宽改成 `width:100%`、9px → 12px；窄屏 `#progMatrix` 不再横向滚动，改成「姓名+百分比 / 条 / 按钮」三行。
- `p2.html`：结构换成 `prog-head + progStats + 三个 prog-block`，每个小节标题带一句 11.5px 说明；**删掉 `#progScope` 整段**。
- 顺带把老师端角标升到 `v17`。
