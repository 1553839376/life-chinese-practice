# T-031 · 「游戏乐园」提到顶部导航

- **日期**：2026-11-02
- **版本**：v36
- **状态**：已交付

## 一、用户需求（原话）

> 「这个全班一起玩的入口好像没有意义了吧？可以不要。然后这个先选游戏的入口要改个名字，『游戏乐园』是不是可以放在这个位置好一点呢？三个选项分别是认字、游戏乐园、学生练习？你可以先分析一下这样会不会好一点，不急着马上修改」

三条，逐条对应：

1. 「全班一起玩」去掉（或降级）。
2. 「先选游戏」改名「游戏乐园」。
3. 提到顶部导航，和「认字」「学生练习」并列。

用户确认过的三个实现选择（2026-11-02）：

- 第一屏：**四张玩法卡直接铺在页面上**（不是点进去先弹面板）。
- 「全班一起玩」：**删按钮，变第五张「随便玩」卡**。
- 左上角标题「认字乐园」：**改成「生活语文练习台」**（避免和「游戏乐园」撞成两个「乐园」）。

## 三、关键约束（别再改回去）

1. **不新建一屏**：认字和游戏乐园共用 `#scrLearn`，靠 `LEARN.mode` 分叉。另建一屏等于字表、筛选、勾选三套逻辑两处维护。
2. **导航高亮看 `LEARN.mode`，不能只看 `STATE.phase`**：两个模式 phase 都是 `learn`。
3. **玩法卡用 `data-gp`，不能用学字卡的 `data-gk`**：那条委托读 `CARD_CH`，在乐园里是 null。
4. **窄屏两处收法缺一不可**：只收字号在 360 上仍折行；只隐藏「学生」不收字号在 390 上仍折。
5. **`#learnBody` 的收起是刻意的**：没选玩法时字格不可见，免得「点字卡弹出学字卡」走错门。
6. 「随便玩」**不进选字态**、点了直接开局；其余四张卡才进 `pickBegin`。
