# T-008 · 「拼词语」题型（v14）

| 项 | 内容 |
|---|---|
| 用户原话 | 「我建议是内置一个词库，然后每个汉字都有对应的 1-2 个词语可以组词，老师在练习端选择了组词练习，就是依据选择的汉字来出对应的词语题目，一次练习多个词语」 |
| 用户给的样子 | 「下面有散乱的各种字 人、大、太、阳、木、头，然后学生就可以从中找出全部三对词语」 |
| 状态 | done（2026-10-22，v14 已上线） |
| 影响面 | 新增第 6 个题型；词库从"空仓库"变成真实出题来源 |

## 1. 关键判断：不新建词表，词表已经在字库里

用户说「内置一个词库，每个汉字 1-2 个词语」。先查了内置字库（`lib.js`，700 条）：

```
700 条全部有「组词」栏（0 条空缺）
按中文逗号拆开去重 → 972 个词，其中 969 个是双字词、3 个是三字词
每个字 1~2 个词（只有 5 个字只有 1 个）
```

也就是说**词表已经在了**，而且是教材配套的组词。所以没有另存一份 JSON——
另存一份就会和字库分叉（老师改字库、词表不跟着变），这也违反了 v11 定下的
「字表只认显式数据」的思路。改成 `wordBank()` 每次开题时从
`STATE.chars[].words` + 老师自建词库现抽，5 ms 级开销，永远同步。

## 2. 出题规则（用户那次举例正好是最优解）

一屏 **3 个词 = 6 个字块**，打乱后让学生两两点选。用户举的「人、大、太、阳、木、头」
正好拼出 `大人 / 太阳 / 木头`——实测第一组出的就是这三个词。

| 规则 | 为什么 |
|---|---|
| 只收双字词 | 教材组词 969/972 是双字；三字词拆开拼对特需孩子太难 |
| 词的任一个字在学生字表里才出 | 这就是用户说的「依据选择的汉字出词语」 |
| 两个字都在字表的词优先（tier 0） | 孩子看到的字块都认识，注意力放在"组词"上 |
| 同组字块不共用 | 一定 6 个字块、每个字只出现一次，规则干净 |
| 后面几组尽量换字（`rep` 评分） | 20 个字的字表能覆盖 18 个字，不至于三组都在练同样 6 个 |
| **任取两字不能拼成本组以外的词** | 否则孩子拼出「大小」却判错，会以为程序坏了 |
| 顺序反过来也算对 | 先点「人」再点「大」，孩子心里是「大人」，不该纠正他的手指顺序 |

## 3. 语音

新增 1 条指令句：`q_word`「找出下面的词语。」（edge-tts 晓晓，rate=-10%，
24kbps/22050Hz/mono，与其余 1690 条参数完全一致）。

- **读题不念词**：念了就是把答案给了孩子。G1 有护栏（`quizSay` 的拼词语分支不许出现 `q.words`）
- 拼对后把**整词**念一遍（`say('大人')`，走 `wordKey` 整词录音，不是逐字拼）
- 拼错说「再试一试。」（复用已有 `fb_again`）
- 整组拼完说「太棒了！」（复用 `fb_win`）

## 4. 记分口径

拼对一个词，给**词里属于学生字表的那两个字**各记一次独立答对。

词的另一半可能是字库里孩子还没学的字（`tier 1`），**不记分**——
记进去会让「已掌握」虚高，档案里的字表字数也会对不上。
G1 护栏：`wbLogWord` 体内必须有 `charsOf`。

结算正确率按**词**算，不按组算：8 个词拼对 6 个 = 75%。
按组算会出现「一组没拼完就崩成 0%」或者「3 组全对 100%」的失真。

## 5. 踩到的坑

**① 题量被"字数"截断**。第一版把 `total`（已按字表字数截断）当词数用，
6 个字的字表 → 只出 2 组。拼词语的题量是**词数**，与字数无关，
改成读 `stu.count` 原始值，`groupN = ceil(count/3)`，上限 4 组。

**② 字表小时整组重复**。只有 2 个字的字表（吸、冻），3 组全是「吸水/冰冻」。
加了 `usedW` 惩罚（前面组出过的词压到最低分）+ 整组都是旧词就收工。

**③ `dead` 跨组累积**。排除歧义词用的 `dead` 集合忘了每组重置，
导致第 2、3 组可选词越来越少。忘了重置的"临时黑名单"是经典坑。

**④ 语音键漏了一半**。`gen_tts.py` 加了句子、`p_voice.json` 加了音频，
但 `p8.js` 的 `SENT_FULL` 没加映射，结果读题回退成逐字念「找、出、下、面、的、词、语」。
e2e_av 断言 `q_word` 直接抓到。

**⑤ 测试字库的组词栏是空的**。smoke2 的 mock 字库 8 条 `组词: ''`，
拼词语一条词都抽不到，`STATE.quiz` 直接是 null、下一行断言崩溃。
只在本节临时注入组词（不改全局 SEED，避免影响前面字卡/配对断言）。

**⑥ CSS 类名进不了符号表**。manifest 的符号检查只认 `function/var/id`，
`wb-tile` 这种类名匹配不到，门禁报"缺 5 个"。类名改由 G1 字符串检查覆盖。
