# T-028 · 老师入口改双击（v34）

> 提出：2026-11-02　交付：2026-11-02　版本：v34
> 关联：`T-024`（老师端入口分页）、`T-027`（同一批「按钮手感」问题）

## 一、老师原话

> 「把老师那个图标的触发方式改为双击吧，长按有点难触发。学生其实也不会去按那个按钮。」

## 二、长按为什么难触发

`p6.js` 原先的写法：

```js
entry.addEventListener('pointerdown', down);   // down 起一个 900ms 定时器
entry.addEventListener('pointerup', up);       // up / pointerleave / pointercancel
entry.addEventListener('pointerleave', up);    //   任意一个都把定时器清掉
entry.addEventListener('pointercancel', up);
```

三条取消监听，等于**只要手指有一点点位移、或者提前半拍松手，长按就作废**。而且屏幕上没有任何进度反馈——按了没反应，只能重按一次。老师经常一只手拿平板、另一只手点，这个手势本来就难成立。

老师自己给的第二个理由更关键：「**学生其实也不会去按那个按钮**」。老师按钮是 13px 灰字的小胶囊，藏在右上角，孩子不会主动去点它。为了防一个几乎不存在的误触，让老师每天多按两次，是划不来的。

## 三、改法

### 1. 自己数两次 `pointerup`（`p6.js`）

```js
var tapAt = 0, tapX = 0, tapY = 0;
var TAP_GAP = 520, TAP_SLOP = 40;
entry.addEventListener('pointerup', function(e){
  var now = Date.now(), x = e.clientX || 0, y = e.clientY || 0;
  var twice = (now - tapAt < TAP_GAP)
           && Math.abs(x - tapX) < TAP_SLOP && Math.abs(y - tapY) < TAP_SLOP;
  if (twice){ tapAt = 0; openTeacher(); return; }
  tapAt = now; tapX = x; tapY = y;
});
```

- **不挂浏览器自带的双击事件**：触屏上各内核派发时机不一致，`pointerup` 在 iPad / 安卓 / 鼠标上都稳，一套判定三端同手感。
- **520ms**：老师反应慢半拍、平板常贴钢化膜，300ms 太紧；520ms 仍远小于「学生乱点两下」的间隔。
- **40px 落点**：按钮 38px 高，手抖到别处不算同一个位置。
- **`tapAt = 0` 归零**：连点三下不会第二次触发。
- 长按那套（`pointerdown` + 900ms 定时器 + 三个取消监听）整段删掉。

### 2. 挡掉「双击放大」（`p1.html`）

```css
.nav-teach{ ... touch-action:manipulation;user-select:none;-webkit-user-select:none }
```

不写的话第二下点击会被浏览器当成双击缩放手势吃掉，页面还会放大一次——手机上等于永远差一下。

### 3. 文案改口

| 位置 | 原来 | 现在 |
|---|---|---|
| `#btnTeacherTop` 的 `title` | 长按 1 秒进入老师端 | 连点两下进入老师端 |
| `#pickEmpty` 空态 | 请长按右上角「老师」约 1 秒 | 请连点两下右上角「老师」 |
| `p5.js` 五处空态提示 | （长按约 1 秒） | （连点两下） |

## 五、踩的坑

1. **jsdom 没有 `PointerEvent`**。测试里用 `new w.MouseEvent('pointerup', {clientX, clientY})` 派发——事件类型字符串是自由的，`addEventListener('pointerup')` 照样收得到，坐标也能带。
2. **护栏判「不许再出现 dblclick」会命中自己的注释**。第一版注释里写了「不依赖 dblclick（触屏派发不一致）」，被 `'dblclick' not in _ent` 判红；把注释改成「不靠浏览器自带的双击事件」。**判旧词之前先看看自己的注释**。
3. **`pointerup` 不冒泡到按钮之外**：按住后拖出按钮再松手，事件不打到按钮上，所以不需要额外的 `pointerleave` 重置。
4. **别用 `dblclick` 兜底**：会和自己的判定重复触发，`openTeacher()` 第二次会把 `TEA_TAB` 重置回名单，看起来像「点了两下反而丢了档案页」。

## 六、遗留

- 老师若嫌 520ms 仍然短（按不利索），只改 `TAP_GAP` 一个数；若嫌孩子误入，可降到 380ms。
- 入口仍无「第一次点成功」的视觉反馈（只有 `:active` 变底色）。若老师反馈「点了没反应，不知道要两下」，可加一个 420ms 后出现的「再点一下」小提示——但那会让第二次点击落在一句新出现的文字旁边，需要再量一次位置。
