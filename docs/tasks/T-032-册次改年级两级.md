# T-032 · 册次改成「先年级、再册次」两级（+ 错误音调小）

- **日期**：2026-11-03
- **版本**：v37
- **状态**：已交付

## 一、用户需求（原话）

> 「目前的错误音效有点大声，调小一些。然后认字这个（截图：一排 22 个册次胶囊）找册的地方我发现如果是六年级五年级要拉很久很累，有没有其他办法去更好的呈现。你可和我讨论一下」

两件独立的事：

1. 错误音效调小。
2. 册次条太长，高年级要拉很久——**先讨论，不要直接改**。

## 二、先算了一遍字库分布（决定了问题有多严重）

| 年级 | 字数 | 在原来的册次条上 |
|---|---|---|
| 一 | 17 | 最左 |
| 二 | 42 | 靠左 |
| 三 | 63 | 中间 |
| 四 | 151 | 偏右 |
| 五 | 197 | 靠右 |
| 六 | **230（全库 33%）** | **最右，要拉 3~4 屏** |

不是「册次多」本身的问题，而是**字多的册次全压在右边**。教低年级的老师几乎不用动，教高年级的每天拉到底——所以这个抱怨只会来自高年级。

## 三、讨论过、没有采用的方案

| 方案 | 为什么不选 |
|---|---|
| 一行下拉（当前册次 + 点开分组面板） | 最省地方，但多一层弹层；v36 刚把玩法卡从弹层里搬出来就是因为「藏起来找不到」 |
| 22 个胶囊全部折行铺开 | 要 5~6 行、占半屏，字格被推到下面 |
| 把「写 / 认」合并成 14 个册次 | 横滚少 36%，但丢掉「会写 / 会认」的区别——特需班恰恰吃这个区别 |
| 记住上次选的册次 | 用户明确选了「每次回到全部 700」，不做 |

**用户 2026-11-03 确认**：方案 A（年级两级），默认每次回到「全部 700」。

## 五、关键约束（别再改回去）

1. **两级是有顺序的**：`#gradeStrip` 必须在 `#stageStrip` 之前。先年级、再册次，反过来就没法「点一个年级列出它的册次」。
2. **`.stage-strip[hidden]{display:none}` 不能删**：`.stage-strip{display:flex}` 是作者样式，会盖掉 `[hidden]` 的 UA 默认 `display:none`，删了这一行「没选年级时册次条收起」立刻失效（表现为空的一条 12px padding 吊在字格上面）。
3. **换年级必须把册次清空**：`LEARN.stage = ''`。不清的话「六上·写」会留在「一年级」里，字格直接是空的。
4. **搜索是跨册次的临时态**：`renderGradeChips` 里「全部」高亮、年级不高亮；`renderStageChips` 里直接收起。否则会出现「亮着一上、却列出全库搜到的字」。
5. **字表没有册次时不能崩**：`gradeOf('')` 返回空 → 年级只剩「全部」，第二级永不出现。已选年级在新字表里不存在时（导入备份换过字表）自动退回「全部」。
6. **年级胶囊不写字数**：7 个字带字数在 390 上放不下，一行会折；字数放第二级（「全年级 230」「六上·写 50」）。
7. **窄屏第二级不能又退回横滚**：六年级 5 个胶囊要挤进 354px，靠 ≤480 的 14px 字号 + 7px 内边距 + 隐藏字数，实测 390 宽 `scrollWidth === clientWidth`。
8. **错误音的口径变了**：不再要求「比正确音响」，因为方波同一峰值的主观响度远超 triangle。改成两头卡 0.18~0.31。
