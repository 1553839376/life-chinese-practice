## 三、实现要点

### 1. 铅笔图标

```html
<button id="sheetTrace" class="sheet-trace-hint" type="button">
  <svg class="sth-i" viewBox="0 0 24 24" aria-hidden="true" focusable="false">
    <path d="M3 17.4V21h3.6L17.3 10.3l-3.6-3.6L3 17.4z"/>
    <path d="M20.6 6.9a1 1 0 0 0 0-1.4l-2.1-2.1a1 1 0 0 0-1.4 0l-1.7 1.7 3.5 3.5 1.7-1.7z"/>
  </svg>描一描
</button>
```

`.sth-i{fill:currentColor;stroke:none}`——图标跟着按钮文字色，绿色描边按钮里就是绿的。

### 2. 滚动位置记忆

```js
var SCROLL_MEM = {};
function showScreen(name){
  var prev = STATE.phase;
  if (prev && prev !== name){
    SCROLL_MEM[prev] = window.pageYOffset || document.documentElement.scrollTop || ...;
  }
  ...
  var y = SCROLL_MEM[name] || 0;
  window.scrollTo(0, y);
  if (y > 0) setTimeout(function(){ window.scrollTo(0, y); }, 0);
}
```

- 只记「离开时」的位置，进入新屏仍从顶部开始（`SCROLL_MEM[新屏]` 默认 0）。
- 补一次 `setTimeout(0)`：屏幕刚从 `hidden` 变可见时高度还没算完，直接滚会落在半路。
- **不能用 `requestAnimationFrame`**——后台标签/无头环境里可能一直不跑。

### 3. 选人卡

```js
'<button class="stu-card" data-stu="...">' + avatarHTML(s,'stu-av') +
  TAG_STU_NM + esc(s.name) + '</span>' +
  '<span class="stu-tag' + (s.types.length ? '' : ' warn') + '">' +
    (s.types.length ? s.types.length + ' 个题型' : '还没排练习') + '</span>' +
'</button>'
```

`.stu-grid{display:flex;flex-wrap:wrap;justify-content:center;gap:18px}`，卡片 200px 定宽（窄屏 140px）。
**不用 `grid:auto-fill 1fr`**：只有一个学生时那张卡会拉成一整行，横得难看。

table.grid .stu-nm{font-size:15.5px;font-weight:800;text-align:left}

`@media (max-width:820px)` 里把 `td` 内边距 12→8、题型列 250→170，名单自然宽 735 → **667px**，768 平板竖屏正好放下。

### 5. 学生档案独立成页

```
老师端标签：学生管理 │ 学生档案 │ 字库 │ 词库 │ 进度总览
```

- `#tpProf` 里两态：`#profPick`（全班档案卡，默认）/ `#stuProfile`（逐字档案，原来的 DOM 整体搬过来）。
- `renderTeacher()` 里 `if (TEA_TAB==='prof') renderProfRoute();`，路由只看 `PROF_NAME` 有没有对得上的人。
- `openStuProfile(name)`：`TEA_TAB='prof'` → 先 `syncActive` 再 `renderTeacher`。
- `closeStuProfile()`：`PROF_NAME=''` → 回档案卡列表。
- `openStuForm()`：`STU_FORM_FROM = (name && PROF_NAME===name) ? name : ''`，若当前不在学生管理则切过去。
- 保存/取消后 `STU_FORM_FROM` 有值就回到那个人的档案。
- `drillStudent` 的 `STATE.fromTeacher` 从 `true` 改成记标签页（`'prof'`），返回时才回得到档案页。

## 五、踩的坑

1. **测试按下标点标签**：`click(teaTabs[1])` 在加了「学生档案」之后指向了档案页，字库/进度页一长串断言连锁红。改成 `data-tp` 查找——以后再加标签也不会错。
2. **`.stu-nm` 只加在选人卡上**：表格里姓名用的是 `TAG_STU_SPAN`（只有数据表绑定属性、没有 class），所以「同一行不换行」的样式静默失效。给 `TAG_STU_SPAN` 补 `class="stu-nm"`。
3. **「在学 0」不一定是数据错**：`stuProfile(s)` 直接算拿到的是没同步的 `active`，先 `syncActive(s)` 才是「点进去看到的那 6 个字」。
4. **无头浏览器窗口宽度被钳到 500px**：`--window-size=430` 截出来的图右边被裁是假象，判溢出只能读 `scrollWidth === innerWidth`（这次三档都相等，没有真溢出）。

## 六、遗留

- **≤640px 的名单要横向滚**才看得到「操作」列（7 列自然宽 667px）。老师日常是笔记本/平板，暂时可接受；若常用更小的屏，可以在窄屏隐藏「最近练习」列。
- 档案卡目前不显示「本周新增掌握几个字」，老师若要看趋势再加。
