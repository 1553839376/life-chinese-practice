## 一、早读模式：发四张牌，一张张翻开带读（09:20~11:00）

老师：「乐园里面增加一个早读模式，老师可以选择几个字，然后轮播读，留足时间给学生跟读。最好是有动效的可以吸引学生注意力。我提供几个你看哪个好。一种是发牌的，一次发四张拍，一张一张自动翻开读。然后或者是搞一个吹泡泡的机器，自动出泡泡，泡泡里面有字可以跟读你看看哪个好」。

- **两个选项里选了发牌**，理由五条（跟读画面必须静止 / 翻开即提示 / 矩形能放 144px 的字 / 泡泡的飞行时间带走节奏 / 戳泡泡已经是另一款游戏）。写进代码注释、`T-040` 和变更日志各一份，怕以后有人再拿泡泡重做。
- 三个口径老师当场选：**5 秒跟读**、**只念这个字**、**牌面只显示大字**。
- 实现：`#scrRead` 新屏 + 乐园第六张卡 `data-gp="read"`（不进 `GAME_KEYS`），复用 v35 的选字流程，`pickStart()` 里 `read` 交给 `startRead()`。发牌 / 翻牌 / 5 秒进度条 / 暂停继续 / 离开收摊，全在 `p7.js` 末尾一块里。
- **5 秒只有一个来源**：`READ_HOLD = 5000` → 写 `--hold` → CSS `animation:rdHold var(--hold,5s)`。
- 暂停用的是 `readWait(ms, fn)`：把「还剩多久」和「等完做什么」一起存，所以停在「5 秒跟读」或「1.7 秒换批」都能接上。

**三个坑**：
