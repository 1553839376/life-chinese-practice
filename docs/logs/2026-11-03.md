# 2026-11-03 工作日志

## v37 · 册次改两级 + 错误音调小（T-032）

老师两条：「错误音效有点大声，调小一些」「找册的地方如果是六年级五年级要拉很久很累，有没有其他办法去更好的呈现。你可和我讨论一下」。

### 先算数，再给方案

统计字库分布才发现真正的毛病：**不是册次多，是字多的册次全在最右边**。一年级 17 个字在最左，六年级 230 个字（占全库 33%）在最右。所以这个抱怨只会来自高年级老师。

把四条路摆出来让老师选（两版界面图 + 代价说明）：A 年级两级、B 一行下拉分组面板、折行铺开、合并「写/认」。老师选 **A**，默认册次选 **每次回到「全部 700」**（不做「记住上次」）。

### 实现

| 文件 | 改动 |
|---|---|
| `p2.html` | `#gradeStrip` 加在 `#stageStrip` 之前；`#stageStrip` 初值 `hidden` |
| `p1.html` | `.grade-strip`（grid 等分、`max-width:560`）、`.grade-chip`；**`.stage-strip[hidden]{display:none}`**；≤480 第二级 14px / padding 7 / 隐藏字数 |
| `p7.js` | `LEARN.grade`、`GRADES`、`gradeOf`、`renderGradeChips`；`renderStageChips` 只渲染该年级；`learnList` / `stagePool` 加年级分支；委托加 `.grade-chip` |
| `p8.js` | `sfxNo` 0.32/0.30/0.30 → 0.22/0.21/0.20 |
| `e2e_av.js` | 错误音峰值口径改「0.18~0.31」+「不低于正确音 ×0.7」 |
| `smoke2.js` | 新增 §31，23 条 |
| `run_gate.py` | 新增 9 条 v37 护栏 |
| `manifest.json` | 符号 +3，smoke2 基线 577 → 600 |

### 三个坑

1. **`.stage-strip[hidden]{display:none}` 必须手写**：`.stage-strip{display:flex}` 会盖掉 `[hidden]` 的 UA 默认值。少了这行，「没选年级时收起」变成「空一条 padding 吊在字格上面」。
2. **换年级不清册次 → 空字格**，而且不报错、界面上什么都没显示。委托里必须 `LEARN.grade = …; LEARN.stage = '';`。
3. **窄屏差 1px**：六年级 5 个胶囊在 390 上实测 367/366。这类问题不会报错，只能实测宽度；收到 padding 7 才变成 366/366。

### 说个反直觉的

错误音「有点大声」不是设错，是**方波和 triangle 的感知响度不是一个量级**：同样的 0.32，方波听起来比 triangle 响得多，而错误音原来是 0.32、正确音才 0.26——等于「错了比对了还响」。所以只压幅度（-3.2 dB），音色、走向、时长一律不动，试听页保留了 0.32 / 0.22 / 0.18 三档给老师自己挑。

### 验收

- `build/_probe_v37.py`：年级 7 个、`gradeH=56`、不溢出；点「六」→ 230 字 / 5 个册次；点「六上·写」→ 50；回「全部」→ 700；「一」→ 17 / 3 个册次；搜索 → 册次条收起、「全部」高亮。
- 390 宽 iframe：`stageW=366/366`，两级胶囊高都 44px。
- 门禁 **136 项**全绿；测试 747 → **771**（smoke2 577 → 600、e2e_learn 37 → 38）。
- 产物 15,419,489 B / md5 `55683d9f…`，**v37 未发布**（线上仍是 v36）。

## v38 · 同音字不再当干扰项 + 听写加「看一眼」（T-033）

### 用户原话

> 「听读音找汉字的时候要避免选项出现同音字。刚刚读音读的是和，但是选项有禾、和，学生选错了。另一个就是听写要有个选项是给学生看一眼，然后就关掉的。方便提示一下子想不起来的学生。目前现有的是无法关掉的」

### 做了什么

| 位置 | 改动 |
|---|---|
| `p5.js` | `pyKey` / `SAME_SOUND_TYPES` / `allCharsOn` / `pickDistract`；`buildQuestions` 收 `type`；`wgPeek` + `PEEK_SEC=3`；`hwFootHTML` 加 peek 按钮；`wgHint` 保持永久亮答案（老师入口，按老师意见改回）；`resetQState` 清 `peeked` |
| `p6.js` | 委托加 `peek` 分支 |
| `p1.html` | `.wg-box.peek .wg-ans{opacity:.88}`、`.hw-btn:disabled`、≤520px `.hw-acts.four` 2×2 网格 |
| `smoke2.js` | §31 三按钮改四；新增 §32（6 条）+ §33（17 条） |
| `run_gate.py` | 9 条 v38 护栏 |
| `manifest.json` | smoke2 基线 600 → 627 |

### 三个坑

1. **倒计时按钮光剩一个「3」会被当成坏了**：宽度一下缩成小块。改成「看一眼 3」，文字留着、只减数字。
2. **窄屏四个按钮折成 3+1**：`flex-wrap` 的默认行为。改 `grid-template-columns:1fr 1fr`，390 实测 2 行 2 列、每个 155×50。
3. **测试造字表抄错字段**：`CHARS` 是 `{c:汉字, w:组词}`，`STATE.chars` 是 `{w:汉字, words:组词}`，直接 `Object.assign` 过去会得到 0 个字的字表，`startQuiz` 静默 return——表现出来是「进不去听写」，很容易误判成功能坏了。

### 说个反直觉的

同音字那条不是「选项抽得不好」，而是**这道题本来有两个正确答案**：hé 的声音里，「和 / 禾 / 河」没有任何区别。所以修法不在出题技巧上，在判据上——按**去声调**的拼音分组，连「喝 hē」也一起排掉，因为特需孩子本来就分不清声调。

### 验收

- `build/_probe_v38.py`：`acts=再听一遍/看一眼/擦掉/写好了`、`actsClass=hw-acts four`；点一下 `peekAns=大`、`peekLabel=3` → 1 秒后 `看一眼 2` → 3 秒后答案空、`看过了`；390 `rows=2 cols=2 overflow=false`。
- 门禁 **145 项**全绿；测试 771 → **798**（smoke2 600 → 627）。
- 产物 15,426,320 B / md5 `7fbd101c…`。
