## T-010 · 老师端词库预填内置组词（v15 已上线）

**用户原话**
> 你这个词库还是空的呀，可以用你内置的汉字的组词先把词库放下这些词语

### 判断：不是没数据，是数据没露面

v14 的 `wordBank()` 一直有 **969 个双字词**（字库「组词」栏派生），拼词语出题正常。
但老师端词库页渲染的是 `STATE.words`——只有老师自己录的词，新装页面一条都没有。
所以「词库是空的」是**界面问题**，不是数据问题。这一点先确认，否则会去补一份不该有的词表。

### 做法

| 层 | 改动 |
|---|---|
| 数据层 `p4.js` | 新增 `builtinWords()`（字库组词栏派生 + 双字过滤 + 两字拼音拼合），`wordBank()` 改为复用它再并入老师自建词 |
| 渲染层 `p6.js` | 新增 `wordRowsHTML()` / `fillWordFilter()` / `copyBuiltinWord()`；`renderWordList` 分两源渲染 |
| 结构 `p2.html` | 筛选 label「筛选分组」→「来源」；提示语改成「这张表默认就有词」 |
| 样式 `p1.html` | `.sp-builtin` / `tr.tr-builtin` / `.td-dim`；窄屏隐藏第 4、5 列 |

内置词是**只读派生视图**，不落 `STATE.words`：否则字库一改就分叉、备份多 87 KB、老师删了还会"删了又回来"。
想改就点「收进词库」复制一份，之后可编辑/停用/删除；同名词出题时按 `byW` 去重。

### 踩坑

1. **窄屏挤成两行**：「收进词库」被拆成"收进/词库"。先试 `min-width:600px` 横滚 → 按钮滚出屏幕（看不见等于没有）。最终按列的重要性砍掉「释义/例句」「图示」（内置词这两列本来就空），剩 5 列正好塞下。
2. **G1 护栏钉在旧结构上**：`wordBank` 体内有 `STATE.chars` 这条，派生点迁到 `builtinWords` 后必红。这是**改设计**不是功能坏了 → 改判新结构（`builtinWords` 体内有 `STATE.chars` + `wordBank` 复用），项数不减，另补 2 条新护栏。教训仍是那句：门禁红了先分清是「回归」还是「设计变了」。
3. **截图共用浏览器数据目录**：三个场景同一个 `--user-data-dir`，localStorage 累积，第二张图显示「我的词库 3 条」（实际只点了 1 次）。改成一场景一目录才干净。
