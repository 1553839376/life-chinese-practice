### 网络与 clone（踩到的坑）
- 本机有两层代理：shell 环境变量 `HTTP_PROXY=127.0.0.1:61773`（WorkBuddy 沙箱出口代理，**对 GitHub 返回 502**）；macOS 系统代理 `127.0.0.1:12450`（scutil 配置，**可用**）。
- git **不读** `HTTP_PROXY` 环境变量，直接 clone 会走 61773 → 502 失败。
- 成功命令：
  `env -u HTTP_PROXY -u HTTPS_PROXY HTTP_PROXY=http://127.0.0.1:12450 HTTPS_PROXY=http://127.0.0.1:12450 git -c http.proxy=http://127.0.0.1:12450 -c https.proxy=http://127.0.0.1:12450 clone ...`
- `npm install` 同理要带 `HTTP_PROXY=http://127.0.0.1:12450`，否则装不了 jsdom。
