## v27：听写拆成两个 + 认字乐园加笔顺描写（T-023）

老师两句需求：「上次让你增加了汉字听写，但是你是词语听写，我建议可以分开来，是两个练习，汉字听写和词语听写。
还有，在最开始的全班都可以学习的地方应该增加一个描写。就像练习那样的。而且应该有笔顺才对。
笔顺是用灰色底图汉字上的动画变红色来先呈现怎么写，再让学生描写」。

**拆分听写**：`writesWord()` 只认「词语听写」，`isDictation()` 认两个；汉字听写只出一个方框、答案取单字，
词语听写按字数给格、答案取整词。老学生由 `migrateTypes()` 自动补一项（幂等 + `bak-T023` 备份），老师可取消勾选。
词语听写先筛「组词栏里真有 2~4 字词」的字，凑不出时给明确提示而不是空白页。

**笔顺描写**：学字卡加「描写这个字」。三层画法 —— 灰底整字 / 已写完的填红 / 当前笔裁到自己轮廓里画粗线
（`lineWidth 300`）。一笔 300ms 长出来，播完整字红着停 0.7s 再淡回灰底（提示语写的是「照着灰字描一遍」，
底字是红的就自相矛盾）。不判分、不写记录。561 字 / 4168 笔从 1.20 MB 压到 558 KB（数字 → 2 字符 base36，
往返校验 0 处不符），产物 14.10 → 14.66 MiB。

**这个坑值得记一辈子**：hanzi-writer 的笔顺数据 **y 轴朝上、基线 900**，canvas 朝下。第一版直接照抄，
截图里「上」的长横跑到最上面、整个字上下颠倒。jsdom 没有 canvas 实现，结构断言全绿也发现不了，
只能靠无头浏览器截图。中间还误判了两轮（以为「长横没填」「y 反导致漏笔」），最后把每一笔单独画到临时 canvas
数像素（`木[1172,2055,1104,1455]`）才确认填充正常——**肉眼判断 canvas 图形一律不可靠，先数像素**。
另外发现 headless 截图的 canvas 层不刷新（静态画一帧后截图仍是动画最后一帧，`getImageData` 却是对的）。

**结果**：门禁 **84 项 0 红**（G0 分片 12 → 15、G1 新增 10 条、资产加 `stroke_chars = 561`），
测试 **620 项**（smoke2 407 → 451）。版本 v27。

## v28：学字卡瘦身 + 笔顺放慢（T-023 返工）

老师看了 v27 的实际界面，三条意见（附截图）：

1. 「不需要什么只看拼音和再听一遍这些词语，你直接在这个字旁边放一个喇叭的标志就好了呀」
2. 「这个描写的位置很奇怪，这么大个框横在这也不是很好看，给我优化一下这个布局和样式」
3. 「描写我点进去看了下，速度太快了，学生无法反应」

**改法**：两个大按钮 → 汉字右侧一个 48px 圆形喇叭（点一下有一圈脉冲）；「只看拼音」删掉。
描写入口从占满整行的绿框改成**点汉字本身**（86px，本来就是这张卡上最大的点击目标）+ 一行小胶囊说明。

**节奏才是真问题**：v27 一笔 300ms，看起来不算快，但**笔间 0 停顿**——`SO_GAP_MS = 120` 从 v27
就在文件里，却从来没被插进播放序列，一笔滑到下一笔，孩子看不出笔画在哪收、下一笔在哪起。
现在每笔 640ms（8 帧 × 80ms）+ 笔间 340ms + 起手先停 600ms，「男」7 笔从 2.1 秒变成 7.1 秒。

**顺带修了一个测试盲点**：`soPlay` 原来先判画布、后生成 `seq`，而 jsdom 没有 canvas → 直接 return →
`SO.seq` 永远是空数组。第一次跑新增的节奏断言就 4 条全红，才发现「节奏」这一类断言以前根本量不到。

门禁 84 → 88 项，测试 620 → 629 项，全绿。产物 14.67 MiB，v28。

## v31 · 题型进度并进题型名、「下一个题型」收成胶囊（T-025）

- 结算页主按钮：`width:100%` + 76px 高的深绿板子 → `inline-flex` + `999px` 圆角的胶囊，

- 题型进度：原来「带框的一排题型名」+「另一排号码圈」两套东西（老师说的「割裂」）；
  现在圆点长在题型名正下方，每格画一段横线、格子首尾相接拼成一条通到底的线。

**两个判断值得记**：
- 折行不是靠「缩字号硬挤」解决的，是靠 `grid-auto-flow:column + 1fr` 让 9 格等分一行。

- 连线不加额外 DOM：每格自己 `::before{left:0;right:0}`，相邻格无缝即自动接上；
  第一格切左半、最后一格切右半，避免线头戳到屏幕边。

**量和验**：1080/900/768/700 一行，660/640/600/520/500 三行；所有宽度 `scrollWidth < innerWidth`、
