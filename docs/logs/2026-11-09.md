## 三、v50 · 练习汉字跨天才算掌握（T-043）

**老师**：「现在练习汉字的退出机制是什么？我感觉才练过一次下次打开就没有这个字了学生还是不熟悉的」，
解释现状后选「改成跨天才算（推荐）」。

**先诊断再改**：临时探针实跑确认不是「练一次就换」，而是旧 `levelOf()` 只看
`alone >= 3 && wrong <= 1`，一轮 9 个题型都从同一批在学字出题，一天里很容易攒够 3 次；
`syncActive()` 立刻把字移出在学名单补新字，换出后降级也不会自动回来。

**做了什么**：`build/p4.js` 加 `LS_SOLO = 'wb2_solo_days_v1'` / `soloLoad()` / `soloDays()` /
`soloMark()`，重写 `levelOf()`；`build/p5.js` 两处独立答对写分点接 `soloMark(r.key, todayKey())`。
只加一个跨天条件，`syncActive()` 一行没动。老云端已掌握、本机没有日期记录的老数据**不追溯**。

**踩的坑 / 注意**：

1. `soloLoad()` 把整张表缓存在模块级 `SOLO`，测试里光 `localStorage.removeItem()` 清不掉；
   §43 的 `v50_reset()` 改成**清空缓存对象本身的键**再删 localStorage，否则前一段写过的日期
   会串到下一段断言里。
2. 造在学名单的学生，`active: []` 不能保证目标字进得去——`syncActive()` 按
   `stuProfile().focus` 补位，而「练习中」排在「待学」之后。要显式把目标字放进 `active`，
   否则「同一天还在名单」这条断言假绿。
3. 跨天用的第二个日期不能写死 `2026-11-10`：万一当天就是这天，会被同日去重吃掉。
   §43 用 `new Date()` 加一天现算。
4. 文档里的版本角标文案 `v49 · 内置词 969` 在 STATE.md 和功能清单里各有一处，
   `check_docs.py` 会卡「一句话现状」里的旧角标，两处都要改。

**验收**：门禁 **211 项 0 红 / 1048 项测试 0 失败**（报告 `harness/reports/gate-20261109-1116.md`）。
smoke2 新增 §43 **28 条**（849 → **877**），G1 新增七条护栏，manifest 登记四个新符号。
