# 2026-10-29 · 拼词语「一人」误判（T-019 → v26）

## 事

用户报：拼词语一屏 6 个字块，把「一」和「人」拼在一起，程序说「拼不成词」，可「一人」是词。
探针复现：字表 一二个人大工只太阳头 时，4 组里 3 组有这问题（一人 / 人头 / 人大）。

## 根因（两层，都要记住）

1. `wbCrossHit` 只查 `wordBank().byW`（969 条，字库「组词」栏派生）。「人」在字库里只有
   `大人、工人`，所以「一人」「人头」「人大」查不到 → 放行。**有限词表兜不住开放组合**，
   补多少条都会漏。
2. 判分只有「命中本组 3 个词」一条路，拼不上就 `sfxNo()` + `.shake` + 提示「拼不成词」
   —— 这句是假话，且不记错（`right`/`logs` 不动），纯粹体感上「我拼对了你说我错」。

## 改法（v26）

- `CROSS_TEXT` 1734 条常见搭配（两字都必须在字库 561 字里、不在词库 972 条里），只做互斥。
- `wbCrossScore()` 分**硬冲突**（词库内另一个词 → 永不接受）与**软冲突**（搭配表里的词 → 尽量避开）。
- `buildWordGroups` 用「软冲突预算 K」：K 从 0 起，凑不满 3 词才放到 1/2/3，前一档结果不丢。
- 判分侧：去 `sfxNo()`、去 `.shake`，改 `.wb-back` 轻退回；提示「上面没有「一人」这个词」；
  题目提示「照着上面 3 个词拼」；**不新增语音句**（会退化成逐字念）。

## 结果

门禁 64 项 0 红 / 496 项测试（smoke2 319→327）。APP_VER v26，产物 14,719,316 B
md5 `122e26b8…`。**未发布，线上仍是 v25**。

撞词组：高频 20 字 81.3% → 50.0%（2.04→0.50 个/组），随机 20 字 37.5% → 0%，
满 3 词的组始终 100%。

## 坑（这几条最容易再犯）

- **一刀切退档比不改更差**：最初「预算 0 凑不满就整组退回只查词库」，1734 条表下撞词率
  从 81% 反升到 75% —— 表大几乎每组都退，一退全退。必须预算渐进，前一档结果不丢。
- **表大小不能用「当前表的命中数」衡量**：200 条时看着撞词率低，其实是表跟字表不匹配、
  根本没命中。尺子必须固定（完整 1734 条），两种字表（高频 / 随机）分开报。
- **测量前先对齐字表**：`ALL.slice(0,8)` 是「一二人手男女」这种超常用字，跟随机 20 字
  完全是两回事，指标会互相打架，白写 5 个探针。
- **python 写文件默认 `\n`→`\r\n`**：`_cross_final.txt` 每行带 `\r`，`Set.has('一人')` 恒 false，
  白跑一轮 0%。`build_html.py` v8 就踩过一次。
- **冒烟里 `wordBank()` 无参拿缓存**，两次调用间 STATE.chars 变过 → byW 跟预期不一样。
  纯函数断言传写死的 byW，不依赖当时状态。

## 留下的

- 搭配表手写整理，一定还有漏网词；漏了不崩，只是那次拼上去被退回。补的口子在
  `docs/tasks/T-019` 第五节（源数据 `build/_cross_words.txt`，成品 `_cross_final.txt`）。
- 高频字表还剩 50% 是数学必然（20 个超常用字 380 种组合大量本身是词），由「不再判错」兜住。

- `fillGroup()` 改成**凑满 2 个词就 break**，预算 K 只在连 2 个都凑不出时才递增。
- 判分与文案**整体回退 v25**：`sfxNo()` + `.shake` + 「这两个字拼不成词，再试试」；
  语音「再试一试」；题面「点两个字，拼成一个词」；`p1.html` 的 `.wb-back`/`wbBack` 整段删掉。

## 重测（`probe_final.js`，120 组，尺子固定 1734 条）

难词 0 次。门禁 64 项 0 红 / **498 项**，产物 14,720,645 B md5 `6c60954d…`。**未发布，线上仍是 v25**。

## 门禁假红（最有价值的一条）

跑门禁报 `smoke2 328 通过 / 0 失败`（要求 >= 329）——**没有 FAIL，只是少跑了一条**。

- 根因：第 727 行「逐个词 assert 词位」的循环跑 `words.length - 1` 次，3 词跑 2 条、2 词跑 1 条。
  v26 允许出 2 个词后基线 329 随机掉到 328。
- 另外两个 `if` 包裹的断言块（错拼 5 条、提示 2 条）也会因随机数据整段跳过。
- 修法：循环只动手、末尾一次性核对词位；错拼改成「优先真·不成词，挑不出用任意非目标词」
  （判分只认本组目标词）；提示按钮先断言可点再点。连跑 7 次（含 2 词/3 词）恒 329 / 0 失败。

## 教训

- **用户说「避免撞词」就只改撞词**。判分口径、题面、提示一个字都别顺手动，动了必返工。
- **「0 失败但项数少」= 断言没跑到**，先数 `ok()`，别翻业务代码。
- **断言条数不能依赖随机数据**：`for` 里的 `ok()`、`if (...) ok()` 都是定时炸弹。
- 文档里的数字**每次都要脚本现算**：第一轮写的「96% 出 3 词」是另一个字表口径，重测后是
  「随机 100% / 超高频 65%」，已把 STATE、变更日志、任务卡、日志四处一起改。

# 第三轮：词的难度改成「相对学生」（HARD_TEXT 作废）

老师澄清：同一个「统一」，一年级学「一」太抽象，六年级学「统」就正常 —— **难度是相对学生阶段的**。

## 改法

- 删掉 `HARD_TEXT` / `hardSet()`（158 条固定黑名单，会把「统一」永久判死）。
- 新增 `charStage(c)`：`lib.js` 每个字都有 `g`（教材册次）→ 一上=0 … 六下-认=21，跨册取**最早**。
- `stuStageLevel(stu)`：字表册次的**中间值**（不是最高值，防一个字表超前字抬全部门槛）。
- `wordFitsStu(ca,cb,a,b,lv)`：两个字都在字表→放行；只有一个在字表→超纲字最多高 `WB_STAGE_GAP` 册。
- `WB_STAGE_GAP = 4`：量出来的拐点（2 册时一上字表只出 2.2 组，4 册回到 4.0 组、最深只到二上「个」）。

## 验证

- 一上 10 字：4 组/局，最深二上（「个」），出女人/小手/男生/三个/五天，**碰不到「统一」**（统差 19 册）。
- 六上 20 字：4 组/局，全 3 词，「统一 / 系统」正常出现。
- 门禁 64 项 0 红 / **503 项**（smoke2 329→334）。产物 14,721,586 B md5 `79d76e78…`。**未发布**。

## 教训

- **别把观察直接变成规则**：老师报「统一太抽象」不等于「统一是禁词」，要先问「在什么条件下抽象」。
- **库里已有的数据别再手写一份**：册次就写在 `lib.js` 每个字上，我绕过去白写 158 词。
- 数据有脏点：`天气`（气=五上-认）、`夏天`（夏=三下-认），所以门槛不能卡太死，4 册比 2 册更稳。

# 第四轮：修「一天只有一个字」（T-020，v19 遗留 bug）

老师截图：在学字数 8、字表 28 字，学生主页「今天练这 1 个」只有一个「女」；正在学 1 / 排队 26 / 已学会 1。

## 病根

`syncActive()` 的 `quota = first ? cap : dropped` —— 只认「练到已掌握让出」这一种空位。
**字表后来变大、在学字数被调大都不认**；上限调小时 ① 循环还会把多出的截掉，调回来找不回。
复现三条路径（`build/_probe_active.js`）：1→28 字卡在 1；上限 1→8 卡在 3；8→1→8 卡在 3。

## 改法

- 新增 `stu.off` + `offList()`：`actDel` 移出时记，`actAdd` 加回时删 —— 给「移出」按钮留痕迹。
- `syncActive` 改成**只要没满就补满**（补位跳过 `off`），三种空位一视同仁。
- `mergeCloudStudents` 把 `off` 像 `chars` 一样从本机带过来（云端没这列）。
- 新语义：**在学字数＝手上练的字数，永远补满；移出＝换字**。

## 验收

老师那份数据（28 字 / 上限 8 / active 只剩「女」）实跑：在学 8、今日字单 8、主页 8 个字块、字卡 8 张，
已学会 1 正确退出、排队 19。门禁 64 项 0 红 / **513 项**（smoke2 334→344）。产物 14,722,935 B
md5 `c702508f…`。老数据不用迁移。

## 教训

- 额度类逻辑（「只补某几种空位」）必须把空位来源列全；这里漏的两种很隐蔽，只有「先建后补字表」才中。
- 为了保住一个按钮而让主流程停摆是亏的 —— 给按钮留痕迹（`off`）比一刀切不补好。
- 先对数字：1+26+1=28 = 字表，说明数据没丢，是名单没补。

老师要：练完一个题型给明显入口进下一个；顶部能看到还剩几个题型；全做完提示完成。
