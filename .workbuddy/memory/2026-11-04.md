## 代理：这次走的不是代理，是直连

`git config http.proxy` 每开机都变，这次对齐到环境变量（54866）后**连续 6 次 `CONNECT tunnel failed, response 502`**。
实测：

- `curl https://github.com`（走 env 代理）→ `CONNECT tunnel failed, 502`
- `curl --noproxy '*' https://github.com` → **200**

结论：**代理通不了的时候先试直连**，别死磕重试。可用命令：

```bash
env -u http_proxy -u https_proxy -u HTTP_PROXY -u HTTPS_PROXY \
    git -c http.proxy= -c http.schannelCheckRevoke=false pull --ff-only origin main
```

拉取耗时 6 分半（9 个版本的大文件），前台跑会被工具超时打断，**要放后台**。
另：`schannel: CRYPT_E_REVOCATION_OFFLINE` 用 `-c http.schannelCheckRevoke=false` 绕过。
